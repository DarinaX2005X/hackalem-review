# HackAlem: каталог проектов

Неофициальный каталог команд HackAlem по 12 кейсам. Поиск по команде, названию проекта и GitHub участника; фильтры; страницы проектов и кейсов; статистика и CSV-экспорт.

## Локальный запуск

Нужен Node.js 22 или новее. Внешних зависимостей нет.

```powershell
npm start
```

Адрес: http://127.0.0.1:4173

## Данные

Готовый публичный набор: `web/data/catalog.json`. У каждой включённой команды один `caseId`. Альтернативные варианты классификатора остаются в локальных рабочих материалах. Исключения и ручные назначения сохранены отдельно.

README и списки участников собираются Python-скриптами без клонирования репозиториев. Для API используется настроенный Git credential helper; ключи не записываются в проект. Исходные кеши, материалы кейсов и внутренние документы исключены из Git.

`GitHub Contributors` показывает зарегистрированных авторов основной ветки. ИИ и служебные боты исключены. Авторы из других веток и коммиты всех участников за период хакатона будут проверяться на следующем этапе; пока этот показатель не рассчитан.

## GitHub Pages

Публикуемая папка: `docs`, ветка `main`.

```powershell
python scripts/prepare-pages.py
npm test
```

Папка `docs` содержит только готовый сайт. Все пути относительные, поэтому сайт работает и в корне localhost, и по адресу проекта GitHub Pages.
