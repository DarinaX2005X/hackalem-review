## Что есть на сайте

- **Каталог:** поиск по команде, проекту и участнику; фильтры по кейсу, языку, README и составу команды.
- **Сортировка:** сначала высокий или низкий балл, название А–Я или Я–А; переход по номерам страниц.
- **Рейтинг каждого кейса:** топ-5 и резерв — команды за пределами пятёрки с точно таким же баллом, как у пятой команды. В общем каталоге эти отметки не отображаются.
- **Страница проекта:** исходный репозиторий, README, технологии, участники и подробный отчёт с обоснованиями баллов и ссылками на код.
- **Проверки:** сборка, запуск, основной сценарий, данные кейса и ограничения проверки. Наличие Live демо-ссылки показывается отдельно от её работоспособности.
- **Статистика и CSV:** состав кейсов, технологии, охват оценками и выгрузка текущего списка проектов.

## Как выставлялись оценки

Каждый проект проверялся отдельно GPT-5.6 Luna. Оценивался пятичасовой прототип: версия решения, доступная до **23 сентября 2026, 18:00 по Астане (UTC+5)**.

Судья использовал [общие критерии](criteries.md) и официальную шкалу кейса, если она предусмотрена. При двух шкалах итог — среднее их сумм; иначе используется общий балл. Недоступность ключей или среды проверяющего не считается недостатком участника, а непроведённые проверки отмечаются явно.

Подробнее: **[методика и правила доказательств](JUDGING-METHOD.md)**. Автоматические браузерные проверки не проводились; технические результаты основаны на чтении кода, командах сборки, тестах и HTTP/API-проверках, описанных в отчётах.

## Запустить локально

Нужен **Node.js 22+**. Для просмотра каталога установка пакетов и API-ключи не нужны: данные и браузерная библиотека уже сохранены в репозитории.

```sh
git clone https://github.com/DarinaX2005X/hackalem-review.git
cd hackalem-review
npm start
```

Откройте [localhost:4173](http://127.0.0.1:4173/).

Проверки кода и данных сайта:

```sh
npm test
```

## Устройство репозитория

| Путь | Содержимое |
| :--- | :--- |
| `web/` | Исходники статического сайта |
| `web/data/catalog.json` | Команды, кейсы и метаданные проектов |
| `web/data/readmes/` | Сохранённые README участников |
| `web/data/reviews/` | Опубликованные отчёты, решения по дедлайну и индекс оценок |
| `docs/` | Готовая копия сайта для GitHub Pages |
| `case-briefs/` | Краткие справки по 12 кейсам |
| `scripts/` | Сбор каталога, подготовка проверок, валидация и публикация |
| `tests/` | Проверки логики и согласованности данных |

Сайт работает без сервера приложений и базы данных. Для обновления копии в `docs/` после изменений `web/` выполните команду с Python 3.10+:

```sh
python scripts/prepare-pages.py
```

GitHub Pages публикует папку **`/docs` ветки `main`**. После отправки обновлённой папки сайт пересобирается автоматически.

Скрипты судейства предназначены для подготовленной локальной среды: им нужны исходные материалы кейсов, служебные данные и инструменты исполнения. Эти материалы, журналы сессий, рабочие копии участников и экспортные архивы не входят в публичный репозиторий. Для просмотра готовых результатов они не требуются.
