# EKT AI Assistant — HackAlem AI

Готовый прототип ИИ-консультанта для сайта **ekt.kz**.

## Возможности

- каталог EKT через Basic Auth;
- `/api/products` + постраничная загрузка;
- `/api/products/detail?id=...` для точной карточки;
- поиск по названию, артикулу и ID;
- нормализация запросов `3×2,5 / 3х2.5 / 3 x 2,5`;
- характеристики, цена, наличие и сертификаты из API;
- релевантные аналоги;
- OpenAI через Responses API;
- PDF, DOCX, XLSX, TXT, JPEG, PNG, WEBP;
- русский и казахский язык;
- память последних найденных товаров в рамках сессии;
- подтверждение перед добавлением в корзину;
- повторная проверка остатка перед добавлением;
- адаптивный интерфейс.

## Быстрый запуск Windows

1. Распакуйте архив.
2. Откройте PowerShell в папке проекта.
3. Запустите:

```powershell
.\run.bat
```

4. Откройте:

```text
http://127.0.0.1:8000
```

## OpenAI

В `.env` добавьте свой API-ключ:

```env
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-5.6-luna
```

Без ключа сайт продолжит работать в fallback-режиме на данных EKT API.

## Важно

Basic Auth находится только на backend и не отправляется в браузер. Файл `.env` добавлен в `.gitignore`; не публикуйте его в GitHub.

Корзина в этом прототипе сессионная. Когда EKT предоставит endpoint реальной корзины, нужно заменить реализацию `app/cart.py`, не меняя чат и интерфейс.
