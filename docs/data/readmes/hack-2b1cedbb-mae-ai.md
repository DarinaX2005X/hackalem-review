# AKIM 5H — AI-симулятор управления городом

**AKIM 5H** — интерактивный симулятор управленческих решений для кейса **«Аким на 5 часов»** от **Astana Innovations**.

Пользователь получает ограниченный виртуальный городской бюджет и принимает **5 последовательных решений** по ключевым направлениям развития города. После каждого решения изменяются городские показатели и пересчитывается **Astana Quality of Life Score**.

> Важно: показатели и коэффициенты используются только внутри виртуальной модели симуляции и не являются официальным прогнозом развития Астаны или оценкой реальных управленческих решений.

---

## Проблема

При ограниченном бюджете невозможно одновременно максимально профинансировать все направления развития города. Каждое решение создаёт компромисс между транспортом, экологией, социальной сферой, безопасностью и цифровыми сервисами.

AKIM 5H позволяет наглядно увидеть эти компромиссы и сравнить последствия разных сценариев.

---

## Основной сценарий

1. Пользователь запускает симуляцию.
2. Получает виртуальный бюджет **100 единиц**.
3. Последовательно проходит 5 направлений:
   - Транспорт
   - Озеленение
   - Социальная сфера
   - Безопасность
   - Городские сервисы
4. В каждом раунде выбирает один из трёх проектов.
5. После выбора:
   - уменьшается бюджет;
   - меняются городские показатели;
   - пересчитывается индекс качества жизни.
6. После пятого решения пользователь получает итоговый экран со своим сценарием.

---

## Городские показатели

Симуляция использует 5 показателей:

- **Мобильность**
- **Экология**
- **Социальная сфера**
- **Безопасность**
- **Городские сервисы**

Начальное значение каждого показателя:

```text
50 / 100
```

---

## Astana Quality of Life Score

Базовый индекс рассчитывается как среднее значение пяти показателей:

```text
QoL =
(Mobility + Ecology + Social + Safety + Services) / 5
```

Для более сбалансированной модели может применяться штраф за сильный разрыв между самым высоким и самым низким показателем:

```text
range = maxMetric - minMetric

imbalancePenalty =
min(8, max(0, range - 15) × 0.25)

QoL = average - imbalancePenalty
```

Итоговый индекс ограничивается диапазоном от `0` до `100`.

---

## Бюджет

Стартовый бюджет:

```text
100
```

Каждое решение имеет собственную стоимость.

Система должна предотвращать ситуацию, при которой пользователь тратит слишком много бюджета и больше не может завершить оставшиеся раунды.

## Примеры решений

### Транспорт

- Адаптивные светофоры
- Приоритетные полосы для автобусов
- Развитие дорожной инфраструктуры

### Озеленение

- Умная система полива
- Районные мини-парки
- Зелёные коридоры

### Социальная сфера

- Доступные общественные пространства
- Молодёжные образовательные центры
- Повышение доступности школ и поликлиник

### Безопасность

- Умное уличное освещение
- Безопасные городские маршруты
- Единый центр экстренного реагирования

### Городские сервисы

- Открытые данные и обратная связь
- Единое приложение города
- Предиктивное управление городом

## Интерфейс

В приложении предусмотрены три основных состояния:

### 1. START

```text
AKIM 5H
ЦЕНТР УПРАВЛЕНИЯ АСТАНОЙ

Пять решений.
Один городской бюджет.
Множество последствий.
```

### 2. SIMULATION

Во время симуляции пользователь видит:

- номер текущего решения;
- оставшийся бюджет;
- текущий индекс качества жизни;
- пять городских показателей;
- три варианта решения.

### 3. RESULT

После пятого решения отображаются:

- итоговый Quality of Life Score;
- итоговые городские показатели;
- использованный бюджет;
- оставшийся бюджет;
- список выбранных решений.

## Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone <URL_РЕПОЗИТОРИЯ>
```

### 2. Перейти в папку проекта

```bash
cd akim-5h
```

### 3. Установить зависимости

```bash
npm install
```

```bash
npm run dev
```

## Как проверить решение

1. Открыть приложение.
2. Нажать **«ПРИНЯТЬ УПРАВЛЕНИЕ»**.
3. Пройти все 5 раундов.
4. Проверить, что:
   - бюджет уменьшается;
   - показатели изменяются;
   - QoL пересчитывается;
   - после пятого решения отображается итоговый экран.

## Ограничения текущего MVP

- Используется виртуальная модель и синтетические коэффициенты влияния.
- Симуляция не является реальным прогнозом социально-экономического развития Астаны.
- Решения не заменяют экспертный анализ и реальные городские данные.
- Текущая версия ориентирована на демонстрацию основного пользовательского сценария хакатона.
