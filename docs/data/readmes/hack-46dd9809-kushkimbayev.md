# EKT Ассистент

## Сервер

1. Установите Node.js 22.18 или новее.
2. В папке проекта выполните `npm.cmd ci`.
3. Если `.env` отсутствует, скопируйте `.env.example` в `.env` и заполните `OPENAI_API_KEY`, `EKT_API_USER`, `EKT_API_PASSWORD`; установите `DATA_MODE=live`. Готовый `.env` менять не нужно.
4. Запустите файл `Start-EKT.cmd` и оставьте окно CMD открытым.

Сервер: http://localhost:8787. Остановка: файл `Stop-EKT.cmd`.

## Расширение Chrome

1. Откройте `chrome://extensions` и включите **Режим разработчика**.
2. Нажмите **Загрузить распакованное расширение** и выберите папку `extension` из проекта.
3. Откройте https://ekt.kz и нажмите **Консультант EKT**.

Сервер должен работать на том же компьютере. После обновления файлов нажмите ↻ у расширения и обновите страницу ekt.kz.
