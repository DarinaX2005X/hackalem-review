
🚀 Запуск проекта
1. Клонировать репозиторий
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd hack-060b71bf-qanat
2. Установить зависимости

Для работы backend необходим установленный Node.js.

npm install
3. Настроить OpenAI API

В корне проекта создать файл:

.env

Добавить:

OPENAI_API_KEY=ваш_openai_api_key
PORT=3000

⚠️ .env содержит секретный API-ключ и не должен загружаться в GitHub.

В .gitignore должно быть:

node_modules/
.env
4. Запустить AI-сервер

Из корневой папки проекта:

node server/server.js

После успешного запуска в терминале должно появиться примерно:

QANAT AI SERVER

Server: http://localhost:3000
AI:     http://localhost:3000/api/analyze

Для проверки backend можно открыть в браузере:

http://localhost:3000

Сервер должен вернуть:

{
  "success": true,
  "message": "QANAT AI Server работает"
}
5. Запустить интерфейс игры

В VS Code рекомендуется установить расширение Live Server.

Открыть:

index.html

и выбрать:

Open with Live Server

После этого игра откроется примерно по адресу:

http://127.0.0.1:5500/index.html
6. Начать игру

Нажать:

НАЧАТЬ ИГРУ

Игрок распределяет бюджет, выбирает ровно 5 управленческих решений и запускает симуляцию. После расчёта отображаются изменение Astana Quality of Life Score, показатели районов, потраченный бюджет и критические показатели. Затем можно нажать «Получить AI-анализ» — AI объяснит сильные стороны, риски и возможные улучшения выбранного сценария.
О проекте

«Аким на 5 часов» — интерактивный веб-симулятор управления Астаной. Пользователь выступает в роли акима, развивает районы города, распределяет ограниченный бюджет и принимает решения по пяти направлениям.

В игре реализованы система уровней, контроль бюджета, неожиданные городские события, визуализация изменений районов и расчёт Astana Quality of Life Score.

После завершения сценария AI-помощник анализирует решения игрока, показывает сильные стороны и риски стратегии и предлагает рекомендации по улучшению.

Проект помогает в игровой форме понять, как связаны городская проблема → решение → бюджет → последствия → результат.
