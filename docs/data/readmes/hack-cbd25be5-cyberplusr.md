# Граф денег — Cyberplus / HackAlem AI

Добавлен [минимальный OpenAI-агент](docs/AGENT.md): чат, чтение счетов и связей, объяснение очереди проверки. Для включения нужен локальный .env с OPENAI_API_KEY. Кнопка — «ИИ-помощник» внизу справа. Перед отправкой интерфейс запрашивает разрешение на передачу выбранных фактов графа в OpenAI.

Локальное рабочее место AML-аналитика: направленный граф переводов до четырёх переходов, гипотезы ролей, кластеры и объяснимая очередь проверки. React + TypeScript + React Flow; Python + pandas + NetworkX.

## Быстрый запуск на этом компьютере

В терминале VS Code (PowerShell):

```powershell
cd C:\Users\nurik\hack-cbd25be5-cyberplusr
.\.venv\Scripts\python.exe run.py --port 5176
```

Открыть http://127.0.0.1:5176. Если сервер уже запущен, просто открыть адрес. Остановка — Ctrl+C; занятый порт заменить, например, на 5177. Также можно дважды нажать START.cmd (порт 5173).

Команда пересчитывает данные, собирает интерфейс и запускает сервер только на localhost. Первичная установка зависимостей не входит в запуск.

## Установка с чистого клона

Нужны Node.js 20+ и Python 3.12. В корне репозитория:

```powershell
npm.cmd ci
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Распаковать предоставленные организаторами nodes.parquet, edges.parquet и transactions.parquet непосредственно в data/. Затем запустить run.py, как выше. Можно передать другую папку: --data "C:\путь\data".

PowerShell может блокировать npm.ps1: используйте npm.cmd. Активация виртуального окружения и изменение политики выполнения PowerShell не нужны.

Для разработки только интерфейса: npm.cmd run dev. Без локального graph_export.json интерфейс показывает явно обозначенный синтетический пример; реальный граф появляется после запуска pipeline.py или run.py. Чистая установка на другом компьютере ещё не проверена.

## Использование

- Поиск по полному gid открывает узел и сбрасывает фильтры.
- Фильтры: роли, кластер, глубина 0–4. Глубина 0 — исходные seed.
- Окружение: 16, 40 или все прямые соседи; слева входящие, справа исходящие. Стрелки сохраняют направление. Узлы можно перемещать, масштабировать и центрировать кнопкой fit view.
- Обзор: первые 120 узлов по приоритету среди прошедших фильтры. Таблица включает все прошедшие фильтры узлы.
- Цвет по роли или кластеру; суммы на связях включаются отдельно.
- Карточка показывает метрики, объяснение роли и вклад пяти признаков в приоритет.
- Три ссылки CSV выгружают полный рассчитанный результат, независимо от фильтров.

## Ограничения

Правила объяснимы, но не обучены на размеченных ролях: role_score — эвристическая сила подтверждения, не вероятность. Приоритет — очередь ручной проверки, не вывод о виновности. Выборка ограничена июлем 2026, внутрибанковскими переводами от 5 000 KZT и четырьмя исходящими переходами. Отсутствие выхода на глубине 4 означает обрыв наблюдения. Вход неполон, в том числе у seed. Временное совпадение не доказывает передачу тех же денег; суммы на пути нельзя складывать как независимые средства.

Точное посредничество NetworkX и включение JSON в JS подходят для текущего набора, но не для миллиона узлов. Для роста нужны пакетные агрегации Arrow/DuckDB, приближённое посредничество, igraph/NetworKit, локальный API с выдачей окружения и постраничной таблицей. Размер JS-сборки вызывает предупреждение Vite; это известное ограничение прототипа.
