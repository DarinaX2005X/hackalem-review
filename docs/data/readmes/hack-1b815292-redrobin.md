# RedRobin

Прототип ИИ-агента для сравнения двух редакций DOCX-документа: организационная структура, функции подразделений, исчезнувшие и новые обязанности, возможные дубли и конфликты ответственности.

Проект сделан для спец-трека Казахтелеком / HackAlem AI. Пользователь загружает документы "до" и "после", backend парсит DOCX, строит быстрый отчет и показывает выводы со ссылками на конкретные пункты. По клику открывается полный документ с подсветкой найденного фрагмента.

## Что умеет

- загрузка двух DOCX-файлов;
- парсинг структуры документа, пунктов и таблиц;
- быстрый анализ редакций 8 и 9 без долгого AI-пайплайна;
- вывод категорий:
  - какие подразделения были раньше;
  - какие появились после реорганизации;
  - какие функции остались;
  - какие функции пропали;
  - какие функции стали дублироваться;
  - где может быть конфликт ответственности;
  - подтверждающие источники;
- просмотр полного документа справа с подсветкой нужного пункта;
- FastAPI backend + vanilla frontend.

## Быстрый запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Открыть в браузере:

```text
http://127.0.0.1:8000
```

## Настройки

Файл `.env` нужен только локально. Его нельзя загружать в GitHub.

Пример лежит в `.env.example`.

```env
OPENAI_API_KEY=
OPENAI_MODEL=
AI_PARALLELISM=4
MAX_FILE_MB=20
JOB_TTL_MINUTES=60
ANALYSIS_TIMEOUT_SECONDS=300
```

Текущая демо-версия работает в быстром режиме и не требует OpenAI API для основного анализа.

## API

- `GET /health` - проверка сервера.
- `POST /api/jobs` - загрузка документов `before_file` и `after_file`.
- `POST /api/jobs/{job_id}/analyze` - запуск анализа.
- `GET /api/jobs/{job_id}` - статус и прогресс.
- `GET /api/jobs/{job_id}/result` - отчет.
- `GET /api/jobs/{job_id}/documents/{role}` - распарсенный документ для просмотра и подсветки.

## Структура

```text
app/
  api/          FastAPI routes
  models/       Pydantic-модели API и домена
  services/     загрузка, парсинг DOCX, быстрый анализ, отчет
  static/       frontend CSS и JavaScript
  templates/    HTML-страница приложения
docs/           технические материалы
materials/      исходные документы и извлеченные тексты
tests/          тесты
```

## Безопасность

Не загружайте в репозиторий:

- `.env`
- `.venv`
- `.pytest_cache`
- `__pycache__`
- `*.pyc`

`.env.example` загружать можно: в нем нет секретов.
