# ИИ-ассистент для чата на сайте ekt.kz

Прототип для хакатона HackAlem AI, кейс ТОО «Электрокомплект».

Чат-ассистент консультирует по каталогу электротехники. Он показывает наличие, цену, характеристики и сертификаты, предлагает аналоги с объяснением, отвечает об оплате, доставке и минимальной партии, разбирает спецификации из Excel, CSV, Word и PDF. Товар попадает в корзину **только после явного «да»** и не больше остатка.

## Запуск

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
cp .env.example .env
python -m backend.server        # http://localhost:8000
```

Тесты: `pytest`. Оценка поиска и времени ответа: `python -m scripts.run_eval`.

## Структура

```
backend/    сервер, логика диалога, обработка файлов, ИИ-модуль
frontend/   интерфейс чата (десктоп и мобильный)
services/   каталог, поиск, аналоги, корзина, условия покупки, парсеры файлов, API ekt.kz
data/       тестовый каталог и условия покупки
scripts/    синхронизация с API, образец спецификации, оценка качества
tests/      тесты T1–T15 из ТЗ
```

## Данные

По умолчанию используется синтетический каталог `data/catalog.json` (21 товар). Чтобы загрузить данные из API ekt.kz, впишите логин и пароль в `.env` и выполните:

```bash
python -m scripts.sync_catalog
```

Затем укажите в `.env` строку `CATALOG_PATH=data/catalog_ekt.json`.

## ИИ

Без ключа ассистент работает на правилах. Если добавить `ANTHROPIC_API_KEY` в `.env`, модель помогает понимать свободные формулировки. Цены и остатки она не сообщает, они всегда берутся из каталога. Подтвердить корзину за клиента модель не может.

## Ограничения

- Корзина хранится в памяти и сбрасывается при перезапуске.
- Оформление заказа и оплата не подключены.
- Фото не распознаются.
