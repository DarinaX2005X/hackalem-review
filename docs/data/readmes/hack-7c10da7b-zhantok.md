# MusicEdu AI

MusicEdu AI — хакатонный MVP для AI Sana / HackAlem AI: ИИ-платформа для превращения коротких бизнес-задач в готовые практические задания для студентов в сфере музыкального образования.

## Problem

Бизнес, музыкальные школы и преподаватели часто формулируют задачи слишком кратко. В черновике не хватает пользователей, потребности, материалов, ограничений, критериев успеха и формата обратной связи. Из-за этого студенческим командам сложно понять задачу и подготовить полезное предложение.

## Solution

MusicEdu AI помогает бизнесу структурировать задачу:

- анализирует короткое описание;
- задает уточняющие вопросы;
- формирует редактируемую карточку;
- рассчитывает рейтинг готовности;
- показывает недостающую информацию;
- публикует задачу в каталог;
- принимает предложения команд;
- оставляет финальное решение за бизнесом.

Автоматического выбора или назначения команды нет.

## Target users

- представители бизнеса и образовательных организаций;
- преподаватели домбыры, фортепиано, ритма и музыкальной теории;
- студенческие команды;
- организаторы хакатонов и проектного обучения.

## Main user flow

1. Бизнес вводит слабое описание задачи.
2. Локальный ИИ задает минимум 3 уточняющих вопроса.
3. Бизнес отвечает на вопросы.
4. ИИ создает структурированную редактируемую карточку.
5. Система рассчитывает рейтинг готовности 0-100.
6. Бизнес видит прозрачную разбивку и недостающую информацию.
7. Бизнес улучшает карточку с помощью ИИ.
8. Бизнес вручную подтверждает карточку.
9. Задача публикуется в каталог даже при низком рейтинге.
10. Студенческая команда открывает задачу и отправляет предложение.
11. Бизнес вручную принимает или отклоняет предложение.

## Architecture

Frontend-only MVP:

- Vite;
- React;
- JavaScript;
- CSS;
- localStorage.

Состояние хранится в React state и localStorage. Backend, база данных, регистрация и внешний ИИ API не используются.

## AI functionality

Для MVP используется локальная детерминированная AI-заглушка. Внешний AI API не требуется для запуска.

Локальные функции:

- `generateQuestions()` — генерирует уточняющие вопросы;
- `generateTaskCard()` — создает редактируемую карточку из черновика и ответов;
- `calculateScore()` — рассчитывает рейтинг готовности;
- `improveTask()` — добавляет явно помеченные демонстрационные предложения.

ИИ не выбирает команду, не назначает победителя и не добавляет внешние факты.

## AI input/output

AI input:

```json
{
  "initialDescription": "Хочу помочь ученикам домбры больше заниматься дома.",
  "answers": [
    "Начинающие ученики домбры",
    "Есть упражнения и заметки преподавателя",
    "Нужен прототип помощника для практики",
    "Без регистрации и внешнего ИИ"
  ]
}
```

Example local AI prompt:

```text
Проанализируй описание практической задачи.
Определи недостающую информацию.
Сформируй минимум 3 уточняющих вопроса.
Не добавляй факты, которых нет во входных данных.
После получения ответов сформируй редактируемую карточку задачи.
```

AI output:

```json
{
  "questions": [
    "Кто является целевой аудиторией?",
    "Какие учебные материалы или данные доступны?",
    "Какой результат должна обеспечить разработка?",
    "Какие есть ограничения?"
  ],
  "taskCard": {
    "title": "Название",
    "context": "Контекст",
    "need": "Потребность",
    "targetUsers": "Пользователи",
    "materials": "Данные / материалы",
    "constraints": "Ограничения",
    "expectedResult": "Ожидаемый результат",
    "successCriteria": "Критерии успеха",
    "contact": "Контакт / обратная связь",
    "interactionFormat": "Формат взаимодействия"
  }
}
```

Invalid-response handling:

- если карточку невозможно сформировать, приложение показывает: "Не удалось сформировать карточку. Проверьте ответы и попробуйте снова.";
- пустое название блокирует анализ;
- пустое описание блокирует анализ;
- без минимум 3 ответов карточка не создается;
- публикация без подтверждения блокируется;
- пустые обязательные поля предложения блокируют отправку.

## Scoring formula

Рейтинг готовности рассчитывается от 0 до 100.

| Критерий | Баллы |
|---|---:|
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Связь с бизнесом | 10 |
| **Итого** | **100** |

UI показывает общий рейтинг, progress bar, уровень, разбивку по критериям и список недостающей информации.

## Readiness levels

| Рейтинг | Уровень |
|---|---|
| 0-39 | Черновик |
| 40-69 | В работе |
| 70-89 | Готово |
| 90-100 | Приоритетная задача |

Низкий рейтинг не скрывает задачу, не блокирует публикацию и не блокирует предложения команд.

## Catalog rules

Каталог:

- показывает все опубликованные задачи;
- сортирует задачи по рейтингу готовности по убыванию;
- показывает тему, пользователей, краткое описание, рейтинг и уровень;
- позволяет открыть подробности задачи;
- поддерживает фильтры "Тема" и "Уровень готовности".

Фильтры меняют только текущий вид и не удаляют задачи.

## Proposal system

Студенческая команда отправляет предложение по задаче.

Поля предложения:

- Название команды;
- Идея решения;
- План реализации;
- Предполагаемый срок;
- Ссылка на прототип.

Количество предложений не ограничено.

## Manual business selection

Бизнес видит все предложения и вручную выбирает действие:

- "Принять";
- "Отклонить".

Статусы:

- "Ожидает решения";
- "Принято";
- "Отклонено".

Команда не назначается автоматически. ИИ не выбирает победителя.

## Demo

Рекомендуемый 3-5 минутный показ:

1. Начать со слабого описания: "Хочу помочь ученикам домбры больше заниматься дома."
2. Показать уточняющие вопросы ИИ.
3. Сформировать редактируемую карточку задачи.
4. Показать низкий рейтинг около 30/100 и список недостающей информации.
5. Нажать "Улучшить задачу с помощью ИИ".
6. Показать рост до примерно 80/100 и уровень "Готово".
7. Подтвердить карточку и опубликовать задачу.
8. Открыть каталог, показать сортировку и фильтры.
9. Открыть задачу и отправить предложение команды.
10. Перейти в предложения и вручную принять или отклонить отклик.

На главной странице есть кнопка "Запустить демо", которая восстанавливает подготовленные данные и переводит к созданию задачи. Также есть кнопка "Сбросить демонстрационные данные"; перед сбросом приложение спрашивает подтверждение.

## Validation/test scenarios

- пустое название задачи;
- пустое описание проблемы;
- меньше 3 ответов на вопросы ИИ;

## Limitations

MVP намеренно не реализует:

- backend;
- базу данных;
- регистрацию;
- авторизацию;
- чат;
- уведомления;
- платежи;
- blockchain;
- мобильное приложение;
- распознавание звука;
- pitch detection;
- обучение ML-моделей;
- vector database;
- полный project tracker;
- автоматическое назначение команд.
