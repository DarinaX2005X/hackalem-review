# TaskForge — HackAlem AI MVP

TaskForge превращает короткое описание потребности бизнеса в полную карточку задачи, прозрачно оценивает её готовность и публикует в открытом каталоге. Студенческие команды сами выбирают задачи и отправляют предложения, а бизнес вручную принимает или отклоняет их.

## Запуск

Нужен Python 3.10 или новее. Внешние библиотеки не требуются.

```powershell
python app.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Демо-изменения хранятся в памяти и сбрасываются после перезапуска.

Также проект можно открыть через VS Code Live Server. Если Python API недоступен, приложение автоматически переходит в браузерный режим; задачи, отклики и решения сохраняются в `localStorage` текущего браузера.

## Демонстрация за 5 минут

1. На экране «Создать задачу» нажмите «Вставить пример» и запустите проверку полноты.
2. Ответьте на уточняющие вопросы и соберите карточку.
3. Дополняйте поля и покажите, как рейтинг растёт и пересчитывается.
4. Подтвердите карточку и опубликуйте её.
5. В каталоге откройте карточку и отправьте отклик от команды.
6. В разделе «Отклики» вручную выберите или отклоните предложение.

## Структура

- `index.html` — конструктор, каталог и экран решений бизнеса;
- `styles.css` — адаптивный интерфейс без UI-библиотек;
- `app.js` — клиентская логика, рейтинг, фильтры и API;
- `app.py` — HTTP-сервер и JSON API на стандартной библиотеке Python.

API: `GET /api/bootstrap`, `POST /api/analyze`, `POST /api/tasks`, `POST /api/tasks/{id}/proposals`, `POST /api/proposals/{id}/decision`.

## Рейтинг задачи

Баллы начисляются только после подтверждения карточки:

| Критерий | Баллы |
|---|---:|
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Связь с бизнесом | 10 |

Уровни: 0–39 — черновик; 40–69 — рабочая; 70–89 — готовая; 90–100 — приоритетная. Низкий рейтинг не скрывает задачу и не запрещает отклик.

## AI-функция

`analyze()` — локальная детерминированная заглушка, пригодная без внешнего API.

Вход: `{"description": "Краткое описание бизнеса"}`.

Выход: карточка с извлечённым из исходного текста контекстом, минимум 3 уточняющих вопроса и признак `invented_facts: false`. Заглушка не заполняет отсутствующие факты. Слишком короткий ввод и некорректный JSON обрабатываются ошибкой.

## Проверочные сценарии

- ввод короче 12 символов не проходит валидацию;
- слабое описание создаёт минимум три уместных вопроса;
- заполнение блоков меняет рейтинг согласно таблице;
- без ручного подтверждения задача не публикуется;
- каталог сортируется по рейтингу и фильтруется по теме и готовности;
- число откликов не ограничено;
- команда назначается только ручным решением бизнеса.
