# QALA LAB — улучшаем Астану вместе

Сайт, где жители предлагают улучшения для города, а аким планирует городской бюджет.

- **Гражданин:** создаёт заявления с фотографиями, ставит от 1 до 5 звёзд чужим предложениям и оставляет отзывы.
- **Аким:** видит заявления и пользуется калькулятором — выбирает пять проектов на 1 млрд ₸ и получает анализ результата.
- Есть личный кабинет с аватаркой, настоящая карта Астаны и погода. Аккаунты, фото и заявления сохраняются автоматически.

В ленте уже есть виртуальные жители и примеры заявлений с реальными архивными фото Астаны. Они отмечены **«Демо»**. Это учебный проект, не официальный сервис акимата; роль «Аким» относится к симулятору.

## Самый простой запуск на Windows

1. Установите **Node.js LTS** с [nodejs.org](https://nodejs.org/en/download). В установщике оставьте обычные настройки. Если программа уже установлена, нужна версия 22.13 или новее.
2. На странице [этого репозитория](https://github.com/BAITC-Hacks/hack-d6ae42c3-neuraxis) нажмите зелёную кнопку **Code → Download ZIP**.
3. Распакуйте ZIP. Откройте папку, в которой лежат `README.md` и `package.json`.
4. Дважды нажмите **START-WINDOWS.cmd**. При первом запуске подождите, пока установятся нужные файлы. Нужен интернет.
5. Откройте в браузере **http://localhost:5173**. Окно запуска оставьте открытым.

Готово! Нажмите **«Личный кабинет» → «Регистрация»**, выберите роль и создайте свой аккаунт. Гражданам калькулятор недоступен.

Чтобы остановить сайт, нажмите **Ctrl+C** в окне запуска. Чтобы открыть снова — повторно запустите `START-WINDOWS.cmd`.

## Запуск через терминал (Windows, macOS, Linux)

Откройте терминал **в папке проекта** и выполните по очереди:

```bash
npm ci
npm run dev
```

Адрес сайта: **http://localhost:5173**. В Windows PowerShell используйте `npm.cmd` вместо `npm`, если появляется ошибка о запрете запуска скриптов.

## Подключение AI — необязательно

Без ключа сайт работает и показывает локальный расчёт.

1. Скопируйте файл `.env.example` и назовите копию `.env` (без `.txt`).
2. Откройте `.env` в текстовом редакторе и вставьте **свой** ключ после `OPENAI_API_KEY=`.
3. Сохраните файл и перезапустите сайт.

Ключ передаётся только серверу OpenAI. **Не публикуйте `.env`**: он уже исключён из Git. В GitHub ключа нет. Подписка ChatGPT и кредиты API — отдельные вещи.

## Если что-то не запускается

- **«node не найден»:** установите Node.js, затем откройте окно запуска заново.
- **Адрес не открывается:** дождитесь загрузки и посмотрите строку `Local` в окне запуска — порт может отличаться.
- **Порт 3001 занят:** закройте старое окно запуска этого проекта и запустите его один раз.
- **Нужные файлы не установились:** проверьте интернет и повторите запуск. Через терминал можно выполнить `npm.cmd ci`.

База данных создаётся сама в `data/astana-simulator.sqlite`. Отдельно устанавливать БД не нужно. Не удаляйте этот файл, если хотите сохранить аккаунты и заявления. Карта, погода и AI требуют интернета. Источники фотографий указаны рядом с ними и в [списке источников](public/images/CREDITS.md).

Для проверки кода: `npm test`. Для готовой сборки: `npm run build`, затем `npm start` и адрес **http://localhost:3001**.
