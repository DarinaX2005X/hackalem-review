# EventMatch KZ — подбор event-подрядчиков

Сервис помогает выбрать до трёх подрядчиков из каталога по городу, дате, формату мероприятия, категории и бюджету. Язык и длительность можно задать как дополнительные условия. Рядом с каждым вариантом сервис показывает факты профиля, на которых основан подбор.

## Запуск в Windows

Нужен Python 3.10 или новее.

Откройте PowerShell в папке проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app:app --reload
```

Откройте сайт: <http://127.0.0.1:8000>  
Интерактивная документация API: <http://127.0.0.1:8000/docs>

Чтобы запустить из другой текущей папки, передайте Uvicorn путь к проекту:

```powershell
$project = "C:\Users\Alimz\Downloads\Telegram Desktop\event_matcher_hackathon\event_matcher"
$python = Join-Path $project ".venv\Scripts\python.exe"
& $python -m uvicorn --app-dir $project app:app --reload
```

Каталог ищется относительно файлов приложения, поэтому смена текущей папки не меняет источник данных.

## Личные подрядчики и ИИ-анализ

Исходный `data.csv` — общий каталог и не меняется при добавлении профилей. Чтобы пользователь мог войти по email и хранить собственных подрядчиков:

1. Скопируйте `.env.example` в `.env` в корне проекта. Заполните `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY`. Приложение использует пользовательский токен Supabase Auth и RLS; `SUPABASE_SECRET_KEY` ему не нужен.
2. В Supabase Dashboard откройте **SQL Editor**, вставьте содержимое `supabase/migrations/202609230001_personal_contractors.sql` и выполните его.
3. В **Authentication → URL Configuration** добавьте разрешённые адреса локального приложения, например `http://127.0.0.1:8000/**` и `http://localhost:8000/**`. Если запускаете приложение на другом порту, добавьте его адрес.
4. В **Authentication → Providers → Email** включите регистрацию email/пароль. При включённом подтверждении email ссылка из письма возвращает пользователя в приложение.
5. После изменений `.env` перезапустите FastAPI.

Пользователь может добавлять, изменять и удалять свои профили. Они участвуют в его подборе и скрыты от других аккаунтов. Общий CSV-каталог остаётся доступным всем.

Чтобы включить анализ профиля по кнопке, добавьте `OPENAI_API_KEY` в локальный `.env`. Ключ создаётся в [OpenAI API Platform](https://platform.openai.com/api-keys), хранится только на сервере и не должен попадать в браузер, чат или Git. По умолчанию используется `gpt-6-luna`; модель можно переопределить через `OPENAI_MODEL`. API оплачивается отдельно от ChatGPT. Настройте лимит расходов и уведомления на стороне OpenAI Platform. Без ключа поиск и карточки продолжают работать.

ИИ вызывается только по кнопке «Анализировать с ИИ», получает факты выбранного профиля и условия поиска без контактных данных, не меняет фильтрацию и порядок результатов. Сервер ограничивает частоту до 8 запросов в минуту на аккаунт или IP.

## Как устроен подбор

1. Выбираются профили точного города и категории.
2. Профили, занятые в выбранную дату, исключаются.
3. Проверяются формат и бюджет, а также заданные язык и длительность. Если профиль не содержит подтверждения для запрошенного языка или длительности, он не считается совпадением.
4. Подходящие профили ранжируются по совпадению описания с запросом, близости к бюджету и, если задано, подходящей длительности. Одинаковые оценки разрешаются стабильным ID.
5. На странице показывается до трёх результатов. В объяснениях используются поля профиля и запроса. Синтетические профили, восстановленные города и цены помечаются отдельно.

Пустая выдача разделяет два состояния: категории нет в выбранном городе либо профили категории существуют, но не прошли дополнительные условия. Во втором случае показываются причины отсева; их числа могут пересекаться.

В списке категорий доступны все категории каталога. Те, которых нет в выбранном городе, отмечены рядом с названием; их можно выбрать, чтобы получить отдельное сообщение об отсутствии категории.

## Ограничения

- Общий каталог хранится в `data.csv`; личные профили — в Supabase Postgres. После изменения `.env` перезапустите приложение.
- Релевантность текста вычисляется прозрачным словарным сопоставлением, а не генеративной или семантической моделью.
- ИИ-анализ поясняет факты профиля и может ошибаться; исходные поля остаются видны рядом для проверки.
- Отсутствие записи о занятости означает, что каталог не отмечает дату как занятую; фактическую доступность нужно подтвердить у подрядчика.
- `price_from_kzt` — цена «от». Итоговую стоимость требуется уточнить у подрядчика.
- Сервис не бронирует услуги и не отправляет заявки.
