# EKT AI Assistant

Прототип команды ApexAI для HackAlem AI: ИИ-консультант по электротехнике для сайта ekt.kz. Ищет товары в каталоге партнёра, помогает разобрать запрос голосом, по фото или по документу и предлагает локальный список покупок с явным подтверждением.

## Что умеет проект

- Искать электротехнические товары по артикулу, названию и параметрам; показывать данные каталога EKT.
- Находить кандидатов на замену с объяснением совпадающих параметров. Совместимость нужно дополнительно проверить.
- Принимать голосовой запрос: запись отправляется на распознавание после остановки, текст можно проверить перед отправкой.
- Прикреплять PDF, Word, Excel и JPEG. Пользователь сам нажимает отдельную кнопку анализа; документы и фото отправляются в OpenAI только после этого явного действия.
- Предлагать вопросы о кабеле, монтаже и сертификате после выбора товара. Эти подсказки не добавляют ничего в корзину.
- Добавлять товар в локальный список покупок только после отдельного подтверждения и повторной проверки остатка.
- Показывать официальные контакты EKT.

Цены, наличие и карточки товаров берутся из ответа EKT или помеченного демокаталога. Ассистент не оформляет заказ и не принимает оплату: API партнёра доступен только для чтения.

## Запуск

Нужен Python 3.10 или новее. Внешние Python/JavaScript зависимости для этой версии не нужны.

```bash
cp .env.example .env
# Заполните EKT_USER и EKT_PASSWORD из документа партнёра.
# Для ответов модели добавьте OPENAI_API_KEY. Ключ не отправлять в чат и не коммитить.
python3 server.py
```

Ключ можно ввести без отображения в терминале командой `python3 setup_key.py`, затем перезапустить сервер.

Открыть http://127.0.0.1:8766. По умолчанию сервер доступен только на этом компьютере (`HOST=127.0.0.1`), порт — 8766.

Для автономного показа: `EKT_MODE=demo python3 server.py`.
В режиме `auto` ошибка API включает **явно обозначенный демонстрационный каталог**. `EKT_MODE=live` запрещает fallback. Важно: после смены `.env` сервер нужно перезапустить.

## Источники данных

Документ партнёра предоставляет Basic Auth и только read-only endpoints:

- `https://ekt.kz/api/products`
- `https://ekt.kz/api/products?page=2` и следующие страницы
- `https://ekt.kz/api/products/detail?id=515291`

`catalog.py` загружает страницы до конца/повторения/100 страниц, отражает полноту загрузки в статусе, перепроверяет карточку при подтверждении. Неизвестная схема или сетевой сбой не превращаются в нулевую цену или выдуманный остаток. 23 сентября 2026 после первоначальных таймаутов успешно проверены реальные список и карточка товара 515291: цена 64 920 ₸, quantity=23, stores с остатками по складам. Загружены первые 100 страниц (2000 товаров); это часть каталога. В списке нет остатков: карточка догружается перед показом наличия, подбором аналога и операцией корзины. Минимальная кратность берётся из properties.KRATNOST_MIN.

`data/demo.json` — четыре **демонстрационные** позиции, перенесённые из исходного прототипа; не актуальные цены/остатки магазина. `data/demo-policy.json` — отдельно помеченные синтетические условия покупки. Раздел 6 задания разрешает синтетические данные для прототипа. В live-режиме условия ekt.kz не выдумываются: партнёр должен предоставить подтверждённую политику оплаты/доставки/минимальной партии.

## Архитектура

Браузер (`index.html`, `app.js`, `styles.css`) → Python HTTP API (`server.py`) → EKT adapter (`catalog.py`) / OpenAI Responses API. SQLite в `.runtime/cart.sqlite3` хранит корзины, ожидающие подтверждения предложения и ограниченный контекст. Корзину меняет только код сервера, модель доступа к записи не имеет.

Секреты — локальная `.env` или переменные окружения. `.env` и `.runtime/` исключены из Git. Не использовать `python -m http.server` в корне проекта: запускайте только `server.py`, который отдаёт ограниченный список публичных файлов.

Документация OpenAI: https://developers.openai.com/api/reference/cli/resources/responses/methods/create

## Проверка

```bash
python3 -m unittest discover -s tests -v
```

Тесты покрывают поиск, аналоги, подтверждение корзины и складские ограничения, документы и голосовой запрос, изоляцию сессий, контракт API и защиту сервера.

Сценарий показа в деморежиме:

1. «Есть ли 027228?» → карточка: 23 шт., 64 920 ₸.
2. «Подбери аналог LED STARK 30W» → исходный товар отсутствует, предложен светильник 30W/2400Lm/4000K/IP20; автоматический выключатель не предлагается.
3. «Какие условия доставки и оплаты?» → явно помеченные демонстрационные условия.
4. «Добавь 23 шт 027228» → до подтверждения корзина пуста.
5. «Да, добавь» → 23 шт.; ссылка открывает ту же корзину. Обновить страницу — позиции сохраняются.
6. «Добавь 1 шт 027228» → отказ: суммарное количество превысит 23.
7. Новый запрос или «Отмена» не подтверждают старое предложение.

## Границы версии и интеграция

Это рабочая **корзина прототипа**, не корзина производственного ekt.kz. Партнёр не предоставил write API, механизм авторизации корзины или контракт checkout. Ссылка на внешний ekt.kz не переносит товары и не создаёт заказ. CSV позволяет передать список вручную. Для внедрения нужен серверный адаптер к официальному API корзины, с сохранением явного подтверждения и проверок остатка.

23 сентября 2026 проверен настоящий вызов OpenAI Responses API с локальным ключом, затем сквозной запрос через `/api/chat` на работающем сервере: «Характеристики 027228». Модель вернула описание Legrand DRX250 MT, 3 полюса, 160 А, 18 кА, 400 В AC по реальной карточке EKT. Проверка выполнена отдельно от 16 автоматических тестов с имитацией внешних API. Для запуска на другом компьютере нужен собственный `OPENAI_API_KEY`; ключи и локальная база в репозиторий не входят.

Можно прикрепить до пяти файлов PDF, Word, Excel или JPEG размером до 6 МБ каждый. Они сохраняются только в локальной `.runtime/` и не выдаются HTTP-сервером; для PDF/DOCX/XLSX доступен небольшой ознакомительный фрагмент. После загрузки JPEG пользователь может явно нажать «Найти товар по фото»: OpenAI извлекает видимую маркировку и ищет её в каталоге. На это выполняется один платный запрос к OpenAI; без явного нажатия изображение туда не отправляется. Не загружайте платёжные данные. Поиск без LLM консервативный; для свободных формулировок требуется ключ. Нет бронирования складского остатка, оплаты или создания заказа. База хранит локальный контекст, без аккаунтов и синхронизации устройств. SQLite рассчитана на один процесс; текущая блокировка сериализует запросы. HTTP-сервер предназначен для локального хакатонного показа. Перед публичным размещением нужны production-сервер, HTTPS/Secure cookies, лимиты запросов, сроки удаления сессий, мониторинг и подтверждённые интеграционные контракты.

У PDF, Word и Excel после загрузки есть отдельная кнопка «Анализировать». Только это явное действие отправляет последний прикреплённый документ в OpenAI и расходует API-кредит. Ассистент извлекает видимые артикулы и параметры, не придумывает наличие/цену и показывает карточки только из каталога EKT. PDF отправляется с экономным уровнем детализации `low`.

Голосовая запись ограничена 10 МБ, поддерживаются WebM, MP3, M4A, WAV и MP4. Она не хранится на диске и не отправляется до явного завершения записи пользователем. Распознанный текст сначала помещается в поле ввода — пользователь может его исправить и лишь потом отправить запрос. Официальная документация по распознаванию: https://developers.openai.com/api/docs/guides/speech-to-text

## Публикация для жюри

Для публикации подготовлен `render.yaml` (Render Blueprint, Python, тариф Free). Публичная ссылка появится после создания Blueprint в Render:

1. Войти в Render и выбрать **New → Blueprint**.
2. Подключить GitHub, выбрать `BAITC-Hacks/hack-9f858e1f-apexai`, ветку `main`.
3. Применить Blueprint из `render.yaml` и ввести значения `OPENAI_API_KEY`, `EKT_USER`, `EKT_PASSWORD` в защищённые поля Render. OpenAI-ключ берётся из OpenAI Platform, доступ к EKT API — из документов партнёра. Не добавляйте их в GitHub и не отправляйте в чат.
4. Дождаться успешного Deploy; Render покажет публичный адрес `*.onrender.com`.

Публичная ссылка появится после успешного Deploy. Для этого нужен вход в аккаунт Render и подключение приватного GitHub-репозитория; секреты вводятся в Render Dashboard напрямую.

Бесплатный Render-сервис засыпает после 15 минут без запросов и его локальные файлы теряются при перезапуске/сне. Поэтому SQLite-корзина и загруженные документы на Free-тарифе временные; при пробуждении сайт может загружаться около минуты. Это демо-размещение, не постоянная база заказов. [Ограничения бесплатного тарифа Render](https://render.com/docs/free).

Учитывайте: после настройки `OPENAI_API_KEY` публичные посетители смогут вызывать ИИ и расходовать API-кредит. Следите за лимитами расходов OpenAI. HTTPS для Render Web Service настраивается платформой автоматически.
