# EKT — ИИ-помощник по каталогу

Локальный MVP для демонстрации чата интернет-магазина электротехники ekt.kz. По умолчанию приложение работает в `DEMO_MODE=true`: берет 40 позиций из загруженных материалов кейса, использует SQLite для сессий и корзины и не обращается к API магазина.

## Возможности MVP

- Поиск по артикулу, названию и бренду с нормализацией текста и простым fuzzy matching.
- Карточки товаров с ценой и известными характеристиками.
- Остаток по городу только для товаров, где он есть в исходных деталях. Для товара `027228` каталог содержит общий остаток 23 шт. и остаток Алматы 5 шт.; неизвестные поля не заполняются вымышленными значениями.
- Подбор близких позиций той же серии и сравнение характеристик.
- Контекст сессии хранится в SQLite. Можно спросить про «второй» товар в найденном списке.
- Корзина с двухшаговым подтверждением в чате и окном подтверждения в интерфейсе. Перед записью backend заново проверяет товар, остаток и количество; неподтверждённые запросы, неизвестный остаток и превышение остатка отклоняются.
- Загрузка PDF, DOCX, XLSX и PNG/JPG. Документы разбираются локально; для распознавания изображения нужен `OPENAI_API_KEY`.
- OpenAI chat completions с function calling для свободных запросов (при наличии ключа). Поиск, данные товара, остатки, аналоги и корзина доступны модели как backend tools. Для предусмотренных демо-фраз работает локальный сценарный обработчик и ключ не требуется.
- Отдельный скрипт синхронизации каталога с ekt.kz Basic Auth. В обычном демо-запуске внешнее API не вызывается.

## Требования

- Node.js 20 или новее и npm.
- Python 3.10–3.13.

В Windows PowerShell используйте `py -3.13` или `py -3.12`, если соответствующая версия установлена. Команды ниже показаны для `py -3.13`.

## Установка и запуск

Откройте два терминала из папки проекта.

1. Создайте локальную конфигурацию и подготовьте каталог:

```powershell
if (!(Test-Path .env)) { Copy-Item .env.example .env }
node scripts/prepare_catalog.mjs
```

2. Установите и запустите backend:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r backend\requirements.txt
python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```

3. Во втором терминале установите и запустите frontend:

```powershell
cd frontend
Copy-Item .env.local.example .env.local
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). API и интерактивная документация доступны по [http://localhost:8000/api/health](http://localhost:8000/api/health) и [http://localhost:8000/docs](http://localhost:8000/docs).

Если PowerShell запрещает активацию виртуального окружения, можно не активировать его и запускать `\.venv\Scripts\python.exe -m pip ...` / `\.venv\Scripts\python.exe -m uvicorn ...`.

### Docker

После создания `.env`:

```powershell
docker compose up --build
```

## Настройка переменных

В проекте уже создан локальный `.env`, который исключён из Git. Откройте его и вставьте ключ после `OPENAI_API_KEY=`. После изменения перезапустите backend (или `docker compose up --build`). Проверка `http://localhost:8000/api/health` должна вернуть `"ai_enabled": true`; сам ключ API наружу не передаётся и не возвращается.

| Переменная | Назначение |
|---|---|
| `DEMO_MODE=true` | Локальный каталог из файлов кейса; не вызывает ekt.kz API |
| `OPENAI_API_KEY` | Необязательный OpenAI tool calling и multimodal распознавание изображений |
| `OPENAI_MODEL=gpt-4o-mini` | Модель диалога с function calling |
| `EKT_API_USERNAME`, `EKT_API_PASSWORD` | Basic Auth для явной синхронизации каталога |
| `EKT_API_BASE_URL=https://ekt.kz/api` | Базовый URL API магазина |
| `DATABASE_PATH` | Файл SQLite для сессий и корзины |
| `FRONTEND_ORIGIN` | Origin для CORS backend |

Локальная сборка и основные сценарии работают без OpenAI API key. Без ключа image upload сообщает, что визуальное распознавание отключено; файл остаётся принятым, а поиск в локальном каталоге доступен по тексту.

## Синхронизация каталога ekt.kz

Демо по умолчанию не делает сетевых запросов. Для опционального импорта задайте `EKT_API_USERNAME` и `EKT_API_PASSWORD` в `.env`, затем запустите:

```powershell
python scripts/sync_catalog.py
```

Скрипт проходит `GET /products`, страницы `?page=N`, затем запрашивает `GET /products/detail?id={id}`. Он использует Basic Auth, timeout и три попытки; учётные данные не записываются в каталог. После синхронизации backend читает сохранённый `data/catalog.json`, а не обращается к API на каждое сообщение. Перед production-использованием нужно проверить фактический контракт пагинации API и нормализацию характеристик.

## Демо-последовательность

1. `Найди Legrand` — список локальных позиций.
2. `Есть ли 027228?` — цена и общий остаток из detail-файла.
3. `Есть ли 027228 в Алматы?` — городской остаток из списка складов.
4. `Покажи характеристики` — данные сохранённого выбранного товара.
5. `Покажи аналоги` — близкие позиции серии DRX250 MT с отличиями параметров.
6. `Мне нужно 3 штуки` — запрос подтверждения, корзина пока без изменений.
7. `Да, добавь` — повторная проверка остатка и запись в корзину.
8. `Добавь 100 штук` — backend отклоняет превышение и предлагает остаток, не изменяя корзину.

На карточке товара действие также открывает подтверждение перед запросом `POST /api/cart/add`.

## Ограничения демо и production

- Демо-файлы содержат две страницы (40 позиций) и одну полную детальную запись. Цена и остатки для остальных позиций есть не везде, поэтому UI явно показывает неизвестный остаток.
- Поиск по характеристикам использует поля, извлечённые из названий и одной детальной карточки; для точного аналога нужны полные API details.
- SQLite предназначена для локальной демонстрации. Корзина разделена по постоянному случайному ID посетителя в браузере; это удобство демо, но не способ аутентификации. Перед публичным использованием привяжите корзину к серверной сессии в защищённой cookie или аккаунту, добавьте rate limiting и серверный аудит. В демо остаток проверяется отдельно в корзине каждого посетителя; резервирование общего складского остатка не подключено.
- Реальная корзина сайта не подключена: текущая корзина — локальная демонстрационная таблица SQLite.
- Перед production-синхронизацией следует проверить формат ekt API и поля остатков, а также настроить HTTPS, CORS и ротацию секретов.
