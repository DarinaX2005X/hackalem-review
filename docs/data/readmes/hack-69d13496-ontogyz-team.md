# AI Sana Challenge Hub — Ontogyz

Сервис помогает бизнесу превратить короткое описание проблемы в понятную задачу для команд. AI задаёт уточняющие вопросы и собирает редактируемую карточку; бизнес подтверждает сведения, получает прозрачный рейтинг готовности и публикует задачу.

Команды видят каталог и предлагают решения. Бизнес вручную выбирает одну, несколько или ни одной команды. Подтверждённый этап выбранного отклика даёт команде 10 баллов однократно.

## Запуск из свежего клона: Windows PowerShell

Проверенная среда: Windows, Python 3.12.14. Нужны Git и доступ к приватному репозиторию. Выберите свободную папку; команды ниже создают новую копию `ontogyz-review`.

```powershell
git clone --branch main https://github.com/BAITC-Hacks/hack-69d13496-ontogyz-team.git ontogyz-review
cd ontogyz-review
git log -1 --oneline
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip check
if (-not (Test-Path -LiteralPath .env)) {
    Copy-Item -LiteralPath .env.example -Destination .env
}
```

Если `py` отсутствует, проверьте `python --version` и используйте `python -m venv .venv`. Можно указать полный путь к установленному Python. Активировать окружение не требуется: команды используют его интерпретатор напрямую.

Для живого AI откройте локальный `.env` текстовым редактором и заполните `OPENAI_API_KEY` своим ключом. `OPENAI_MODEL` по образцу — `gpt-4.1-mini-2025-04-14`. Эта модель отвечала в аккаунте команды 23.09.2026; доступ другого аккаунта проверяется отдельно. `.env` исключён из Git, ключ команды в клоне отсутствует. Используется именно `.env`, не `env.env`. Переменные окружения AI имеют приоритет над файлом.

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000
```

После сообщения `Uvicorn running` **оставьте терминал открытым** и откройте [приложение](http://127.0.0.1:8000/) в браузере. [Проверка сервера](http://127.0.0.1:8000/api/health) должна вернуть `{"status":"ok"}`. Остановка — `Ctrl+C`. После изменения настроек перезапустите сервер. Если порт уже занят, используйте `--port 8001` и тот же порт в браузере.

## Проверки

Из корня проекта, во втором окне PowerShell:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -W error::RuntimeWarning -m unittest app.ai.test_service app.ai.test_review_regressions -v
```

AI-тесты подменяют внешние ответы: они не подтверждают доступ аккаунта к OpenAI или качество живой модели. Изолированные проверки интерфейса доступны при работающем сервере на [/static/tests/ui.html](http://127.0.0.1:8000/static/tests/ui.html); они также используют искусственные ответы.

### Что можно проверить без ключа

Каталог, фильтры, просмотр задач, отклики, ручной выбор нескольких команд и начисление баллов работают без AI. В новой базе:

1. Откройте раздел «Команда», выберите уровень «Начальная 0–39» и задачу с 30 баллами.
2. Отправьте два отклика от разных команд: идея и план — от 10 символов, срок — 1–365 дней, ссылка — HTTP(S) URL. `https://example.org/` допустим как явно обозначенная тестовая ссылка, а не действующий прототип.
3. В разделе «Отклики» выберите эту задачу и вручную выберите обе команды.
4. Подтвердите этап одного выбранного отклика: баллы его команды увеличатся на 10. Повторная кнопка недоступна; повторный HTTP-запрос также не начисляет баллы.
5. Перезапустите сервер с тем же путём БД: записи и баллы должны сохраниться.

Без ключа обращение к AI возвращает `503 AI_NOT_CONFIGURED` с читаемым сообщением. Статический ответ не подставляется. Для самостоятельной проверки живого AI эксперт настраивает собственный ключ на компьютере сервера; предоставление ключа организатором здесь не подтверждается.

## Архитектура и правила

Один процесс FastAPI отдаёт HTML/CSS/JavaScript и JSON API. SQLite хранит карточки, команды, отклики и этапы между запусками. AI вызывается только сервером. Публичные схемы и ошибки — в [CONTRACTS](docs/CONTRACTS.md).

| Подтверждённое поле | Баллы |
| --- | ---: |
| Контекст | 10 |
| Потребность | 10 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Контакт бизнеса | 5 |
| Взаимодействие бизнеса с командой | 5 |

Сервер начисляет вес только за содержательное заполненное поле из `confirmed_fields`. «Не знаю» и «Нет данных» не повышают рейтинг. Название в сумму не входит. **100/100 означает полноту подтверждённых сведений, а не их независимую достоверность или готовность решения.**

Уровни готовности в интерфейсе: 0–39 — начальная, 40–69 — рабочая, 70–89 — готовая, 90–100 — приоритетная. Статус публикации задаётся отдельно: черновик или опубликовано. Публикация требует названия, но не минимального рейтинга. Каталог показывает все опубликованные задачи, сортирует по рейтингу по убыванию, затем по ID. Количество откликов не ограничено; выбор каждого предложения независим. Этап разрешён только выбранному предложению и приносит +10 однократно.

## Данные и отдельная репетиция

Новая БД автоматически получает 5 синтетических черновиков, 5 карточек с баллами 30/50/65/75/90, 5 профилей команд и 5 откликов. Набор организаторов не использовался. Происхождение и небольшой CSV для репетиции — в [data/README.md](data/README.md).

По умолчанию база — `data/hackalem.db`; она исключена из Git. Путь задаётся переменной окружения PowerShell `DATABASE_PATH` (для БД значение из `.env` автоматически не читается). Для отдельной репетиции в новом терминале из корня проекта:

```powershell
$env:DATABASE_PATH = "data/rehearsal-01.db"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8001
```

Откройте `http://127.0.0.1:8001/`. Для новой чистой репетиции выберите ещё не существующее имя БД; повторный запуск с тем же именем продолжает сохранённую работу. Рабочую базу удалять не требуется.

- Переключатель ролей не является авторизацией. Доступ общий; защиты записей от изменения другим посетителем и производственного развёртывания нет.
- Данные учебные, экономический эффект и интерес реальных клиентов не измерялись.
- Полный показ с секундомером на итоговой версии, доступ аккаунта экспертов и фактическая подача пока не подтверждены.
