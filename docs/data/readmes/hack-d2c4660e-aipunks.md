# Event Match · aipunks

Подбор event-подрядчиков в Казахстане (#79-lite): до трёх рекомендаций, проверенная доступность, контрастные факты и конкретные изменения условий, если вариантов мало.

Стек: Flutter 3.44.1 / Dart 3.12.1, Node.js 24.16+, SQLite, OpenAI Responses API. Firebase не используется при запуске. Локальный подбор работает без сервера и интернета; AI-редактор — дополнительный слой.

## Запуск

Сначала зависимости Flutter — они нужны и общему Dart-ядру сервера:

```powershell
cd apps/event_match
flutter pub get
cd ../api
npm ci
```

Создайте `apps/api/.env` по `.env.example`, задайте `OPENAI_API_KEY=...` только в этом файле. Ключ не передаётся во Flutter. Затем:

```powershell
npm start
```

Сервер запускается на `127.0.0.1:8787`, автоматически импортирует 500 профилей в `apps/api/data/event-match.sqlite` и создаёт первого администратора, если в базе ещё нет админа.

По умолчанию логин — `admin@eventmatch.local`. Случайный пароль сохраняется в локальный файл `apps/api/data/event-match.sqlite.admin-credentials.json`, исключённый из Git. Свои данные можно задать **до первого запуска** через `ADMIN_EMAIL`, `ADMIN_NAME` и `ADMIN_PASSWORD` в `apps/api/.env`. Повторный запуск не меняет существующие аккаунты и пароли.

Скрипт создания админа находится в репозитории: `apps/api/src/admin-create.mjs`. Его можно запустить отдельно командой `npm run admin:create` из `apps/api`, без запуска API и Flutter. Подробнее — [первый администратор](docs/feature-integration.md#запуск-и-первый-администратор).

В другом терминале из корня репозитория:

```powershell
cd apps/event_match
flutter run -d chrome --web-port=5173
```

После изменения `pubspec.yaml`, добавления фото или шрифтов полностью остановите
старый `flutter run` клавишей `q` и запустите его заново. Hot reload может оставить
старый набор ресурсов: тогда существующий `assets/images/event-table.jpg`
возвращает 404, а шрифты заменяются системными. Фото включено в `pubspec.yaml`;
копировать его в `web/` или подключать через внешний URL не нужно.

Конфигурация Chrome в VS Code использует 5173. В loopback-режиме без ALLOWED_ORIGINS разрешены произвольные локальные dev-порты Chrome; явно заданный список ограничивает их. Если сервер не запущен, приложение загружает встроенный JSONL и показывает локальные объяснения.

Android-эмулятор по умолчанию использует `http://10.0.2.2:8787`. Для физического телефона нужен адрес компьютера в общей сети, настройка `HOST`, локальный токен и разрешение брандмауэра — [инструкция](docs/local-backend.md). Локальный HTTP разрешён только в debug Android; для release нужен HTTPS. iOS в этой конфигурации не проверялся.

## Что реализовано

- Кабинеты клиента/подрядчика, админка и план события перенесены из новых веток и подключены к SQLite.
- ИИ-помощник с уточнениями-кнопками и переписка с опубликованными подрядчиками — в правых панелях.
- Регистрация, модерация публикаций, календари, права доступа и личные данные — через локальный API.
- Запуск кабинетов, выдача первого администратора и ограничения — [инструкция интеграции](docs/feature-integration.md).
- Все жёсткие ограничения, включая календарь площадок и `max_hours: null`.
- Полный набор нарушений; основная причина: формат → язык → часы → занятость → бюджет.
- Детерминированный скоринг: бюджет 0.30, число форматов 0.20, совпадения описания 0.20, языки 0.15, часы 0.15; поправки на происхождение данных.
- Порядок: score ↓, цена ↑, id ↑. Score — соответствие продуктовой эвристике, не рейтинг качества.
- Индивидуальный факт + соответствие бюджету; общие условия в сводке. Почти одинаковые описания не объявляются разными преимуществами.
- До трёх кнопок ослабления, каждая меняет ровно один параметр. Число вариантов пересчитывается.
- Три исхода: подобрали / категории нет / кандидаты не прошли условия.
- SQLite-каталог и постоянный кэш AI; hash каталога и версия алгоритма.
- Переключатель GPT/локальные факты, источник текста в карточке, вклад фич в раскрытых деталях.
- При сбое AI, несовпадении версий или отсутствии ключа — локальная выдача без изменения порядка.

В подборке показаны **1–2 предложения**: подтверждённое условие/цитата профиля и стартовая цена относительно лимита с оговоркой об итоговой стоимости. GPT выбирает порядок двух проверенных предложений; сервер и клиент принимают только точный вариант из `explanation_options`. Это ограниченный выбор формулировки, а не свободное сочинение причин. Без GPT остаются те же проверенные факты. В каталоге GPT по-прежнему генерирует сводку услуг: заголовок «Об услугах» не обещает соответствия заказу. В подборке заголовок «Почему в подборке», неизвестное вынесено в «Что уточнить». Источник GPT отмечается только после принятого ответа модели. [Правила и исследования](docs/match-explanations.md).

Если профили не имеют подтверждённых отличий, карточки честно сообщают об этом. Абсолютная неповторяемость объяснений для таких данных не заявляется. Прежнее ядро учитывает пожелания лексически. Новый помощник разбирает пожелания и отрицания GPT, проверяет признаки по цитатам и явно отмечает неподтверждённые требования; это не гарантия полного смыслового понимания.

## Демо на расширенном каталоге

Все запросы — свадьба, без языка/часов, если не указано иное.

| Сценарий | Условия | Ожидаемый результат |
| --- | --- | --- |
| Плотный пул | Алматы, Ведущий, 06.10.2026, 1 000 000 ₸ | Из 16 прошедших: Кики → Эмилия → Лунный Ветер |
| Соседняя дата | То же, 05.10.2026 | Из 13 прошедших: Эмилия → Лунный Ветер → Лазурный Ветер; исключения по занятости в сводке |
| Редкая категория | Алматы, Флорист, 10.10.2026, 1 000 000 ₸ | Тони Тони Чоппер; предложение 09.10 с двумя вариантами |
| Никто не проходит | Алматы, Ведущий, 26.12.2026, 1 ₸ | Нет результата; повышение бюджета до 650 000 ₸ даёт один вариант |
| Нет категории | Зарубежье, Флорист, 10.10.2026, 1 000 000 ₸ | Отдельный исход и предложения других городов |
| Честная эквивалентность | Алматы, Лайв-бэнд, 23.09.2026, 2 000 000 ₸ | Два близких профиля отмечены как не имеющие уникального преимущества |

Пересчёт без сборки приложения: `dart run tool/audit_catalog.dart` из `apps/event_match`.

## Проверки без сборок Web/APK

```powershell
# apps/event_match
flutter analyze
flutter test

# apps/api
npm test
```

Серверные тесты используют подменный GPT, не тратят API-бюджет. Явный живой тест при работающем сервере: `node --env-file=.env src/smoke.mjs`. Он делает одну генерацию при промахе кэша и повторяет только успешный ответ для проверки кэша.

## Данные и устройство

Исходные `data/catalog.csv` и снимок `data/catalog.original.jsonl` содержат 66 профилей организаторов (13 синтетических). Рабочий JSONL содержит **500 профилей**: исходные 66 без изменений и 434 новых с ID `DEMO-*` и `synthetic: true`. Всего синтетических — 447. В карточках новые записи отмечены как «Демонстрационный профиль · добавлен нами»; их цены, услуги и календари вымышлены.

Из корня: `node scripts/seed_catalog.mjs` воспроизводит тот же каталог без сети. Из `apps/api`: `npm run db:seed` повторно генерирует каталог и атомарно импортирует его в SQLite; `npm run catalog:audit` проверяет уникальность. После изменения каталога перезапустите работающий API и перезагрузите приложение: оба держат снимок в памяти. Для восстановления исходного снимка из CSV: `python scripts/import_catalog.py data/catalog.csv data/catalog.original.jsonl`, затем повторите засеивание.

Редкие категории сохранены по три профиля. Новые календари занимают 30–50% дней осенью и 70–80% в декабре; декабрьские выходные новых профилей заняты. Подробные результаты и границы проверки уникальности — [в отчёте](docs/catalog-seeding.md).
