# Workflow Tool — Task Card MVP & AI Sana Engine
> **AI-конструирование задач из бизнес-потребностей → 100-балльная оценка зрелости → Ранжированный каталог → Отклики студентов и геймификация (+100 XP)**

Полнофункциональная платформа для трансформации неформальных запросов бизнеса в структурированные паспорта задач с AI-интервьюером, 100-балльным скорингом качества, JWT-авторизацией с разделением ролей (`business`, `student`, `admin`), каталогом задач и отбором студенческих команд.

## 🔑 Авторизация и роли (JWT + BCrypt)

Реализована полноценная система аутентификации и авторизации:
- **JWT токены** (HS256) в HTTP-Only Cookies и заголовках `Authorization: Bearer <token>`.
- Хеширование паролей через `bcryptjs`.
- **Роли**:
  - 💼 **`business`**: создание и редактирование задач, AI-конструктор, просмотр входящих заявок студентов, ручной выбор команды-победителя.
  - 🎓 **`student`**: просмотр ранжированного каталога, AI-рекомендации по стеку команды, подача структурированных заявок (идея, план, сроки, ссылка на прототип), получение **+100 XP**.
  - 🛡️ **`admin`**: полная модерация, управление статусами, сброс демо-данных в 1 клик.



## 🔄 8-Шаговый пайплайн AI Sana Hackathon

1. **Черновик бизнеса**: Бизнес-представитель описывает проблему свободным языком.
2. **AI Анализ пробелов & Уточняющие вопросы**: Генерация $\ge 3$ персонализированных вопросов (формат данных, метрики, ограничения).
3. **Синтез паспорта задачи**: Автоматическая сборка структурированной карточки без галлюцинаций.
4. **100-балльный скоринг качества**: Автоматический расчёт готовности карточки по 7 критериям.
5. **Ранжированный каталог**: Сортировка задач по индексу зрелости (`readiness_score DESC`).
6. **Отклики студентов**: Подача структурированных заявок с планом реализации и ссылками на код/прототип.
7. **Ручной выбор бизнесом**: Заказчик отбирает исполнителя.
8. **Геймификация прогресса**: Выбранной команде автоматически начисляется **+100 XP**.

## 🛠️ Запуск проекта вручную

### Вариант 1: Запуск Next.js (Track A — Fullstack)
```bash
# Установка зависимостей
npm install

# Сборка проекта
npm run build

# Запуск продакшн-сервера
npm run start -- -p 3000
```
Приложение откроется на [http://localhost:3000](http://localhost:3000).

### Вариант 2: Запуск Java Spring Boot (Track B — Production Service)
```bash
cd backend-java
export DB_HOST=localhost
export DB_PORT=5432
export DB_NAME=workflow_tool
export DB_USER=postgres
export DB_PASSWORD=postgres

./mvnw spring-boot:run
```
API будет доступно на [http://localhost:8080](http://localhost:8080).
База данных PostgreSQL мигрируется автоматически с помощью Flyway (`V1__init_schema.sql`, `V2__seed_sample_data.sql`).



## 🔌 API Спецификация

| Метод | Эндпоинт | Роли | Описание |
|---|---|---|---|
| `POST` | `/api/auth/register` | Public | Регистрация нового пользователя |
| `POST` | `/api/auth/login` | Public | Аутентификация, выдача JWT |
| `GET` | `/api/auth/me` | Public | Проверка текущей сессии и профиля |
| `POST` | `/api/auth/logout` | Public | Завершение сессии |
| `POST` | `/api/ai/clarify` | Business, Admin | Генерация $\ge 3$ уточняющих вопросов |
| `POST` | `/api/ai/synthesize`| Business, Admin | Сборка паспорта задачи из ответов |
| `GET` | `/api/tasks` | Public | Каталог задач с фильтрацией и ранжированием |
| `GET` | `/api/tasks/{id}` | Public | Паспорт задачи со 100-балльным аудитом |
| `POST` | `/api/tasks` | Business, Admin | Создание карточки с авто-скорингом |
| `POST` | `/api/tasks/{id}/proposals` | Student | Подача структурированной заявки |
| `PATCH`| `/api/proposals/{id}/status`| Business, Admin| Выбор команды (+100 XP) / отклонение |
| `POST` | `/api/seed` | Admin | 1-Click сброс тестовых данных |
