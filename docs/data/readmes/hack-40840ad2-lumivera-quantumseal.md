# hack-40840ad2-lumivera-quantumseal
Hackathon team repository for LUMIVERA QuantumSeal
## Инструменты команды

В работе планируется использовать:

- GitHub — хранение файлов проекта и контроль версий;
- Git и Git Bash — локальная работа с репозиторием;
- Codex — AI-помощник для обучения, объяснения незнакомых заданий, проверки структуры, подготовки черновиков и работы с кодом;
- текстовый редактор — создание и редактирование файлов;
- локальная среда на Windows 11 — запуск и проверка решения.

## Использование AI-помощника

В качестве AI-помощника используется Codex.

Codex помогает:
- понимать формулировки заданий;
- объяснять команды и программный код;
- готовить черновые варианты;
- находить и исправлять технические ошибки;
- проверять структуру и соответствие требованиям;
- вести пошаговую работу с Git и GitHub.

Автор проекта самостоятельно принимает решения, проверяет результаты и несёт ответственность за итоговую работу. Использование AI осуществляется открыто и только в пределах правил хакатона.

## Что можно готовить до официального старта

До официального старта разрешена только организационная и учебная подготовка:

- обучение локальной работе с Codex;
- тренировка понимания незнакомых заданий;
- распределение ролей и времени;
- изучение безопасных принципов кибербезопасности;
- подготовка пустого чек-листа требований;
- тренировка на отдельном синтетическом примере;
- подготовка порядка действий на первые 15 минут.

До официального старта не создаётся готовое решение конкурсного задания и не используются реальные конфиденциальные данные.
