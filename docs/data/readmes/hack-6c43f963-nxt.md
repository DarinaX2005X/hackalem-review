# seelect

**Онлайн-демо:** [https://seelect.reesang.dev](https://seelect.reesang.dev)

Умный подбор event-подрядчиков для Казахстана.  
Хакатон-задача [#79-lite](https://docs.google.com/document/d/1rhR2HFY164BrnkIP39N3usY9fNY4JeAgkPxEzbqL00w/edit?tab=t.9tqw3yk75922#heading=h.t2seklf6n24).

**Стек:** Laravel 13 · Livewire 4 · PHP 8.4 · Alem `qwen3-8` (опционально)  
**Данные:** 66 профилей в `storage/app/private/contractors.csv`

## Питч в двух минутах

### Проблема

Организатор свадьбы, той или корпоратива в Алматы/Астане уже видит каталог. Боль не в том, чтобы «найти ещё ссылок», а в том, чтобы **выбрать**:

- кто свободен в нужную дату (календарь густой, особенно в декабре);
- кто влезает в бюджет;
- кто берёт этот формат и язык;
- и **почему** система предлагает именно этих троих.

Сейчас это ручной перебор: открыть профиль → сверить дату → сверить цену → надеяться, что формулировка «подходит» правда.

### Инсайт

На агрегаторах ценность не в длине выдачи, а в **доверии к shortlist**. Если у каждой карточки есть проверяемая причина — заказчик быстрее идёт в контакт.

### Решение

**seelect** принимает параметры мероприятия и возвращает **до 3 карточек** с объяснением: бюджет, формат, язык, длительность или смысл описания. Без общих фраз вроде «отличный выбор для вашего события».

Занятые на дату не попадают в выдачу. Если вариантов меньше трёх или их нет — система честно говорит почему: нет категории в городе / все заняты / бюджет / формат.

Заказчик может заполнить форму или **написать своими словами** в ИИ-чате (Alem). Дальше тот же строгий подбор.

### Почему это не «ещё один фильтр»

| Обычный каталог | seelect |
| --- | --- |
| Длинный список | До 3 понятных вариантов |
| «Сортировка по цене» | Объяснение, почему именно этот профиль |
| Пустой экран | Три явных исхода словами |
| Только форма | Форма + живой NLP-чат |
| AI «угадывает» занятость | PHP режет календарь до любой модели |

### Что показать на демо

1. Плотная категория (Ведущий, 23.09) → 3 разные карточки, прочитать объяснения вслух.  
2. Сменить дату на 24.09 → выдача меняется (календарь).  
3. Редкая категория (Флорист) → меньше трёх + метка synthetic.  
4. Бюджет 1 ₸ → пустой исход с причиной.  
5. (Опционально) Чат одной фразой на казахском/русском.

### Куда расти

Заявки подрядчику, кабинеты и живые календари, пакеты «ведущий + фото + зал», white-label для агрегаторов, другие города и MICE.

## Как запустить локально

Требования: PHP 8.4+, Composer, Node.js + npm.  
База данных **не нужна**.

```sh
git clone <repo-url>
cd hack-6c43f963-nxt
composer install
cp .env.example .env
php artisan key:generate
npm install
npm run build
php artisan config:clear
php artisan serve
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

Минимум в `.env`:

```dotenv
APP_NAME=seelect
SESSION_DRIVER=file
CACHE_STORE=file
QUEUE_CONNECTION=sync
CONTRACTOR_AI_ENABLED=false
```

Не запускайте `composer run setup` — скрипт шаблона тянет миграции, они здесь не нужны.

### Опционально: ИИ (Alem)

```dotenv
CONTRACTOR_AI_ENABLED=true
CONTRACTOR_AI_PROVIDER=openai-compatible
CONTRACTOR_AI_MODEL=qwen3-8
OPENAI_COMPATIBLE_URL=https://llm.alem.ai/v1
OPENAI_COMPATIBLE_API_KEY=ваш_ключ
CONTRACTOR_CACHE_STORE=file
```

После изменений: `php artisan config:clear`.

Без ключа всё работает: фильтры и объяснения на PHP, чат — пошагово с чипами.

## Что умеет продукт

1. Форма или ИИ-чат: город, дата, формат, категория, бюджет (+ язык и часы).
2. PHP-фильтр: город, категория, свободная дата, бюджет, формат, язык, часы.
3. До 3 карточек: имя, фото, категория, город, цена «от», объяснение.
4. Три исхода: подобрали / нет категории в городе / кандидаты есть, но условия не проходят.
5. Профиль и заявка на запись (демо-контакт поверх рекомендации).

Интерфейс: **kk / ru**, шрифт **IBM Plex Sans**.

## Соответствие заданию

| Требование | Статус |
| --- | --- |
| Вход: город, дата, тип, категория, бюджет; опц. часы и язык | да |
| Выход: ≤3 карточки с объяснением | да |
| Занятый на дату не в выдаче | да |
| Меньше трёх — показать сколько есть и почему | да |
| Детерминизм: тот же запрос → тот же порядок | да |
| Три исхода: matched / no_category / no_matches | да |
| Без общих маркетинговых фраз | да |
| Ответ за разумное время | да |
| Разные даты → разная выдача | да |
| Synthetic / imputed помечены | да |

## Сценарии для проверки

`CONTRACTOR_AI_ENABLED=false`, язык и часы пустые.

| Сценарий | Параметры | Ожидание |
| --- | --- | --- |
| Плотная категория | Алматы, Ведущий, свадьба, **23.09.2026**, 1 500 000 ₸ | 3 карточки: Мицури Канроджи, Эмилия, Сон Гоку |
| Другая дата | то же, **24.09.2026** | Кики (1 карточка) |
| Редкая категория | Алматы, Флорист, свадьба, 23.09.2026, 500 000 ₸ | Тони Тони Чоппер + Тихиро Огино (синтетический) |
| Нет категории | Зарубежье, Флорист, … | «Пока нет в каталоге» |
| Не проходят условия | Алматы, Флорист, …, бюджет **1** ₸ | «Нужны другие условия» + цена выше бюджета |

Повтор того же запроса даёт тот же порядок.

## Как устроено

```text
Форма / NLP-чат
    → ContractorCatalog (CSV)
    → ContractorMatcher (жёсткие фильтры)
         → no_category | no_matches | matched
         → при matched: PHP-объяснения или AI-ранжирование + проверка цитат
    → карточки → подробнее / заявка
```

Идея пайплайна для жюри: **сначала правила, потом речь модели**. LLM не может «дорисовать» свободную дату.

| Файл | Назначение |
| --- | --- |
| `resources/views/pages/⚡contractor-finder.blade.php` | экран: форма, витрина, чат, результаты |
| `app/Services/ContractorCatalog.php` | чтение CSV |
| `app/Services/ContractorMatcher.php` | фильтры, статусы, объяснения |
| `app/Services/AiContractorRanker.php` | опциональный AI-порядок |
| `app/Services/AiContractorConversation.php` | NLP-чат (Alem) |
| `app/Services/ContractorChatGuide.php` | чат без AI (чипы) |
| `storage/app/private/contractors.csv` | каталог |
| `public/images/contractors/` | фото профилей |
