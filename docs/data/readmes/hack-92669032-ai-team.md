# ALN SupplyLens

«ALN SupplyLens — интеллектуальная система формирования и обоснования заказов поставщикам».

Слоган: «Видит реальный спрос. Объясняет каждую закупку».

## Демонстрационный интерфейс

Это статичный, интерактивный фронтенд-прототип без внешних зависимостей. Откройте `index.html` в браузере или запустите любой локальный HTTP-сервер в корневой папке проекта.

```sh
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Что отражает решение

- рекомендации по товарам с остатками, товарами в пути, сроком поставки и минимальной партией;
- прогноз с сезонностью и устойчивым ростом спроса;
- компенсация вероятно упущенного спроса в периоды stockout;
- исключение разовых крупных сделок, включая аномальные продажи одному обезличенному клиенту;
- группировка по поставщикам, краткое объяснение каждой рекомендации, сценарное моделирование и CSV-экспорт;
- подтверждение пользователя перед утверждением: приложение намеренно не отправляет заказ поставщику автоматически.

Все цифры в интерфейсе демонстрационные. Идентификаторы клиентов в модели должны быть только обезличенными.

## Структура

- `index.html` — шесть экранов: обзор, заказы, карточка товара, сценарии, качество данных и экспорт.
- `styles.css` — фирменная дизайн-система ALN SupplyLens.
- `app.js` — навигация, фильтрация, выбор позиций, сценарии, подтверждение и CSV-экспорт.
- `assets/aln-logo.png` — предоставленный логотип, используемый в сайдбаре, шапке, favicon и предпросмотре экспорта без изменения пропорций.
