# TaskBridge AI

> AI-платформа, которая помогает бизнесу превращать размытые запросы в готовые практические задачи для студенческих команд.

## Проблема

Бизнес часто формулирует задачу слишком кратко: не указаны пользователи, данные, ожидаемый результат, критерии успеха или ограничения. Студенческим командам сложно понять, за что браться, а сильные практические задачи теряются.

## Решение

TaskBridge AI проводит бизнес через короткое уточнение задачи, формирует **редактируемую карточку**, считает прозрачный рейтинг готовности и публикует задачу в общем каталоге. Команды сами выбирают интересные задачи и отправляют предложения. Финальное решение всегда остаётся за бизнесом.

## Основной сценарий

1. Бизнес вводит черновое описание задачи.
2. AI выявляет пробелы и задаёт не менее трёх уточняющих вопросов.
3. Бизнес вручную заполняет и подтверждает редактируемую карточку.
4. Рейтинг готовности от 0 до 100 пересчитывается после каждого изменения.
5. Задача публикуется в открытом каталоге.
6. Студенческая команда отправляет идею, план, срок и ссылку на прототип.
7. Бизнес вручную выбирает или отклоняет отклик.

## Прозрачный рейтинг

| Поле | Баллы |
| --- | ---: |
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Контакт и формат взаимодействия | 10 |
| **Итого** | **100** |

Баллы начисляются только за заполненные поля, поэтому бизнес сразу видит, чего не хватает для качественной задачи.

## AI-границы

- AI не придумывает факты за бизнес.
- AI задаёт вопросы только по недостающей информации.
- Карточка редактируется и публикуется человеком.
- AI не выбирает команду и не принимает решение за бизнес.

## Технологии

- HTML, CSS, JavaScript — интерфейс MVP;
- Node.js built-in HTTP server — выдача приложения и защищённый API-маршрут;
- localStorage — сохранение демонстрационных задач и откликов в браузере;
- OpenAI Responses API — генерация структурированных уточняющих вопросов по черновику.

## Быстрый запуск

### Требования

- Node.js 18+;
- ключ OpenAI API для AI-анализа.

### 1. Клонировать проект

```bash
git clone https://github.com/BAITC-Hacks/hack-6e421c7a-k-house.git
cd hack-6e421c7a-k-house
```

### 2. Создать локальный `.env`

```env
OPENAI_API_KEY=ваш_ключ
```

> `.env` не нужно и нельзя добавлять в Git.

### 3. Запустить

```bash
npm start
```

Откройте [http://localhost:3000](http://localhost:3000).

Без ключа интерфейс и ручной сценарий работают, но AI-анализ подставит запасные вопросы.

## Тестовый сценарий демо

1. Открыть «Создать задачу».
2. Ввести: «Нужен сайт для учёта заказов».
3. Нажать AI-анализ и ответить на уточняющие вопросы.
4. Заполнить карточку и показать рост рейтинга с расшифровкой баллов.
5. Опубликовать задачу.
6. В «Каталоге» открыть её и отправить отклик команды.
7. В кабинете бизнеса вручную выбрать или отклонить отклик.

## Раскрытие внешних компонентов

- OpenAI Responses API используется только для вопросов по неполным бизнес-черновикам.
- В браузере используются стандартные Web API и localStorage.
- При разработке применялись Codex и Claude как инструменты помощи в программировании. Весь результат проверяется в этом репозитории.
