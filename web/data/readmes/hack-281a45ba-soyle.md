# SOYLE

**SOYLE** — платформа, которая соединяет бизнес с молодыми специалистами и студенческими командами через реальные практические задачи.

Бизнес описывает проблему своими словами, AI помогает превратить её в понятное техническое задание, после чего команды могут найти подходящую задачу и предложить решение.

## Проблема

Бизнесу часто сложно сформулировать задачу так, чтобы разработчики или студенты сразу поняли:

* что нужно сделать;
* для кого создаётся решение;
* какой результат ожидается;
* какие есть ограничения;
* по каким критериям принимать работу.

Одновременно студентам и начинающим специалистам не хватает реальных задач для получения практического опыта.

SOYLE соединяет эти две стороны.

## Как работает

### 1. Бизнес создаёт задачу

Пользователь описывает проблему обычным текстом.

Например:

> Нам нужен сервис, который поможет автоматизировать запись клиентов и уменьшить нагрузку на администратора.

### 2. AI уточняет требования

AI анализирует описание и задаёт уточняющие вопросы.

Ответы помогают определить:

* контекст;
* потребность;
* целевых пользователей;
* доступные данные;
* ограничения;
* ожидаемый результат;
* критерии успеха;
* формат взаимодействия.

### 3. AI формирует карточку задачи

На основе исходного описания и ответов создаётся структурированная карточка.

Бизнес может вручную изменить любые поля перед публикацией.

### 4. Backend рассчитывает готовность

После подтверждения данных backend рассчитывает **Readiness Score от 0 до 100**.

Рейтинг показывает, насколько полно сформулирована задача.

Он рассчитывается детерминированно и не зависит от оценки языковой модели.

### 5. Задача публикуется

После публикации задача появляется в каталоге.

Команды могут:

* искать задачи;
* использовать фильтры;
* видеть рейтинг готовности;
* получать подбор задач под свои навыки и технологии;
* сохранять интересные задачи.

### 6. Команда отправляет предложение

Команда указывает:

* идею решения;
* план работы;
* срок;
* ссылку на прототип.

### 7. Бизнес выбирает команду

Бизнес просматривает предложения и принимает или отклоняет их.

После выполнения этапа бизнес подтверждает результат и может оставить обратную связь участникам.

## AI

SOYLE использует AI в двух этапах.

**Этап 1 — Questions**

```text
Описание бизнеса
        ↓
   AI Analysis
        ↓
Уточняющие вопросы
```

**Этап 2 — Task Card**

```text
Описание + ответы
        ↓
       AI
        ↓
Структурированная карточка
```

AI не публикует задачу автоматически и не рассчитывает Readiness Score.

Финальное решение и подтверждение данных остаются за пользователем.

## Readiness Score

Рейтинг показывает полноту описания задачи.

| Критерий                 |   Баллы |
| ------------------------ | ------: |
| Контекст и потребность   |      20 |
| Данные и материалы       |      20 |
| Ожидаемый результат      |      15 |
| Критерии успеха          |      15 |
| Ограничения              |      10 |
| Целевые пользователи     |      10 |
| Контакт и взаимодействие |      10 |
| **Всего**                | **100** |

Уровни:

|  Score | Статус       |
| -----: | ------------ |
|   0–39 | Черновик     |
|  40–69 | Рабочая      |
|  70–89 | Готовая      |
| 90–100 | Приоритетная |

Расчёт выполняется backend по фиксированным правилам.

## Запуск

### Требования

* Node.js 22.12+ или 24+
* npm

### Установка

```bash
git clone <repository-url>
cd <project-folder>

npm install
npm run dev
```

После запуска откройте адрес, указанный в терминале.

Обычно:

```text
http://127.0.0.1:5173
```

### Windows PowerShell

Если PowerShell блокирует `npm.ps1`:

```powershell
npm.cmd install
npm.cmd run dev
```

## AI режимы

По умолчанию проект запускается без API-ключа:

```env
AI_MODE=mock
```

Это позволяет полностью пройти демонстрационный сценарий.

Для подключения OpenAI:

1. Создайте `.env`.
2. Добавьте:

```env
AI_MODE=openai
OPENAI_API_KEY=your_api_key
OPENAI_MODEL=gpt-4o-mini
```

3. Перезапустите приложение:

```bash
npm run dev
```

API-ключ используется только на backend и не должен попадать в GitHub.

## Demo Flow

Для быстрой проверки проекта:

1. Откройте приложение.
2. Выберите роль бизнеса.
3. Создайте новую задачу.
4. Введите короткое описание проблемы.
5. Запустите AI-анализ.
6. Ответьте на уточняющие вопросы.
7. Сформируйте карточку.
8. Отредактируйте и подтвердите данные.
9. Посмотрите Readiness Score.
10. Опубликуйте задачу.
11. Переключитесь на роль команды.
12. Найдите опубликованную задачу.
13. Отправьте предложение.
14. Вернитесь в роль бизнеса.
15. Примите предложение команды.
16. Подтвердите выполненный этап.

Таким образом можно пройти основной end-to-end сценарий SOYLE в одном браузере.

## Архитектура

```text
User
 │
 ▼
React + TypeScript
 │
 ├── Task creation
 ├── Catalog
 ├── Team profiles
 └── Proposals
 │
 ▼
Node.js Backend
 │
 ├── AI API
 ├── Validation
 └── Readiness Score
 │
 ▼
OpenAI Responses API
```

В текущем MVP пользовательские данные хранятся локально в браузере.

Backend отвечает за AI-запросы, валидацию и расчёт готовности задачи.

## Ценность проекта

SOYLE превращает:

```text
«У нас есть проблема, но мы не знаем,
как правильно поставить задачу»
```

в:

```text
Понятная задача
        ↓
Структурированные требования
        ↓
Readiness Score
        ↓
Подходящая команда
        ↓
Предложение решения
        ↓
Первый подтверждённый результат
```

**SOYLE — от бизнес-проблемы до первого результата команды.**
