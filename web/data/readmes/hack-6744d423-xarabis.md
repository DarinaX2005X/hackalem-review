# Аким на 5 часов — AI-симулятор управления городом

Пользователь получает бюджет **100 единиц** и данные пяти районов Астаны. Он принимает **ровно 5 решений** из каталога 14 мероприятий, получает итоговый **Astana Quality of Life Score** и разбор плана от AI-советника. Все расчёты делает детерминированный Python-движок. AI ничего не считает: он объясняет уже рассчитанный результат.

Данные синтетические, взяты из датасета кейса. Карта и 3D-макет условные, это не цифровой двойник города.

## Как закрыты требования кейса

| Требование ТЗ | Где реализовано |
| --- | --- |
| Единый виртуальный бюджет и исходные данные | Один файл `backend/src/city_simulator/resources/simulation.v1.json`: бюджет 100, 5 районов, 14 мер, синергии, несовместимости |
| 5 решений по 5 направлениям | Ровно 5 мер, не больше 2 из одного направления, без повторов; для районных мер обязателен район, для городских его быть не должно |
| Автоматический контроль превышения бюджета | Валидатор backend (`budget_exceeded`). Кнопка расчёта неактивна, пока план не проходит проверку |
| Расчёт Astana Quality of Life Score | `Score = 0.7 × среднее по городу (с весами населения) + 0.3 × худший район − 1 × число значений ниже 40`, с учётом лага и синергий (`backend/.../domain/services.py`) |
| AI-анализ решений: сильные стороны, риски, последствия, рекомендации | `ai_service`: модель получает от backend готовый расчёт и возвращает ответ по строгой JSON-схеме |
| Изменение набора решений меняет Score | Каждый расчёт сохраняется. История сценариев доступна на вкладке «Астана» |

Контрольная точка из кейса: без решений Score **52.56**. Пример M7, M8, M10 в Нуре, M12 и M5 в Сарыарке стоит **95** и даёт **56.54**, критических значений **2 → 0**.

## Как устроено

```text
Браузер ──► frontend (React + Vite, :5173)
              │  /api/v1/*  (прокси, без ключей)
              ▼
           backend (FastAPI, :8000) ── правила, расчёт Score, сценарии, история чата
              │  доверенный контекст расчёта             │
              ▼                                          ▼
           ai_service (FastAPI, :8001)              SQLite / PostgreSQL
              │  ключ OpenAI хранится только здесь
              ▼
           OpenAI Responses API (структурированный JSON, стриминг)
```

Единственная точка входа для браузера — backend. Ключ модели лежит только в `ai_service/.env` и не попадает во frontend.

## Что установить

| Что | Версия | Проверка |
| --- | --- | --- |
| Python | **3.12** (backend требует ≥ 3.11) | `py -3.12 --version` / `python3.12 --version` |
| Node.js | **22.16+** (проверено на 24) | `node --version` |
| Ключ OpenAI API | с доступом к модели из `ai_service/.env.example` | — |
| PostgreSQL | не обязателен: для локальной проверки хватает SQLite | — |

## Быстрый запуск: 3 терминала, из корня репозитория

Команды даны для **Windows PowerShell**. Для Linux и macOS отличия указаны под каждым шагом.

### Терминал 1 — backend (расчёт и правила)

```powershell
cd backend
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
$env:DATABASE_URL = "sqlite+aiosqlite:///./.venv/sandbox-local.db"
.\.venv\Scripts\python.exe -m city_simulator.init_local_db
.\.venv\Scripts\python.exe -m uvicorn city_simulator.main:app --host 127.0.0.1 --port 8000
```

Linux/macOS: `python3.12 -m venv .venv`, `.venv/bin/python` вместо `.\.venv\Scripts\python.exe`, `export DATABASE_URL=...` вместо `$env:DATABASE_URL = ...`.

Проверка: <http://127.0.0.1:8000/api/v1/health> отвечает `{"status":"ok"}`, Swagger — <http://127.0.0.1:8000/docs>. Для этого режима файл `backend/.env` не нужен. Запуск с PostgreSQL и Docker описан в [backend/README.md](backend/README.md).

### Терминал 2 — AI-советник

```powershell
py -3.12 -m venv ai_service/.venv
& ./ai_service/.venv/Scripts/python.exe -m pip install -r ai_service/requirements-lock.txt
Copy-Item ai_service/.env.example ai_service/.env
notepad ai_service/.env
& ./ai_service/.venv/Scripts/python.exe -m uvicorn ai_service.app:app --host 127.0.0.1 --port 8001
```

В `ai_service/.env` вставьте ключ в `OPENAI_API_KEY=`. Модель уже указана (`OPENAI_MODEL=gpt-6-luna`), с ней команда проверяла сервис. Если у вашего API-проекта нет доступа к этой модели, укажите любую, которая поддерживает Responses API, Structured Outputs и стриминг. После изменения `.env` сервис нужно перезапустить.

Linux/macOS: `python3.12 -m venv ai_service/.venv`, `ai_service/.venv/bin/python ...`, `cp ai_service/.env.example ai_service/.env`.

Проверка: <http://127.0.0.1:8001/health> отвечает `{"status":"ok"}`. Этот эндпоинт не проверяет ключ: ключ проверяется первым вопросом советнику.

### Терминал 3 — интерфейс

```powershell
cd frontend
Copy-Item .env.example .env
npm ci
npm run dev
```

Linux/macOS: `cp .env.example .env`, дальше те же команды.

Откройте <http://127.0.0.1:5173/>.

## Основной сценарий проверки

Приложение открывается на вкладке **«Песочница»**. Это дополнительная учебная игра «Новый Берег» со своими правилами (бюджет 200, 12 кварталов), она не входит в расчёт кейса. **Сценарий из ТЗ находится на вкладке «Астана»** (или сразу по адресу <http://127.0.0.1:5173/#astana>):

1. Вкладка **«Астана»** → **«Попробовать пример»**. В план попадут 5 мер из примера кейса.
2. **«Сохранить план»** → **«Рассчитать результат»**.
3. На экране результатов должно быть: **Astana Quality of Life Score 56.54** (до плана 52.56), бюджет **95 / 100**, критических показателей **2 → 0**, изменения по пяти районам и вклад каждой меры.
4. Откройте AI-советника. В ответе есть блоки «Сильные стороны», «Риски», «Возможные последствия», «Рекомендации». Числа в ответе совпадают с расчётом.
5. Замените любую меру и пересчитайте: Score изменится. Попробуйте нарушить правило, например добавить M4 и M7 в один район. Расчёт не запустится, валидатор назовёт причину.

Если backend не запущен, вкладка «Астана» работает в явно отмеченном деморежиме. Там показан только пример из кейса (52.56 → 56.54), произвольные планы не считаются.

## Переменные окружения

Все секреты и адреса берутся из `.env` рядом с сервисом. Шаблоны лежат в `*.env.example`, сами `.env` в Git не попадают. Переменные процесса имеют приоритет над файлом.

| Файл | Переменная | По умолчанию | Зачем |
| --- | --- | --- | --- |
| `ai_service/.env` | `OPENAI_API_KEY` | — (обязательно) | Ключ модели; без него советник отвечает `503 ai_not_configured` |
| | `OPENAI_MODEL` | `gpt-6-luna` | Модель с Responses API + Structured Outputs + стримингом |
| | `OPENAI_TIMEOUT_SECONDS` | `45` | Предел ожидания ответа модели, до 120 |
| | `OPENAI_MAX_OUTPUT_TOKENS` | `4000` | Лимит длины ответа, 256–16000 |
| `backend/.env` (необязателен) | `DATABASE_URL` | `sqlite+aiosqlite:///./xarabis.db` | База сценариев; для PostgreSQL см. шаблон |
| | `AI_SERVICE_URL` | `http://127.0.0.1:8001` | Адрес AI-советника |
| | `CORS_ALLOWED_ORIGINS` | `http://localhost:5173,http://127.0.0.1:5173` | Откуда разрешены запросы браузера |
| | `AI_CHAT_REQUESTS_PER_MINUTE` | `10` | Лимит вопросов советнику |
| `frontend/.env` | `PYTHON_API_URL` | `http://127.0.0.1:8000` | Куда проксировать `/api/v1` |
| | `PORT`, `HOST` | `3000`, `127.0.0.1` | Только для `npm run serve` (production-сборка) |

`backend/.env` читается из текущей папки, поэтому backend запускайте из `backend/`.

## Если не работает

| Симптом | Причина и решение |
| --- | --- |
| `ImportError: cannot import name 'StrEnum'` | Python старше 3.11. Пересоздайте `.venv` через `py -3.12` |
| На вкладке «Астана» деморежим | Не запущен backend на `:8000` или в `frontend/.env` неверный `PYTHON_API_URL` |
| Советник: `ai_not_configured` | В `ai_service/.env` пустой ключ или модель. Заполните и перезапустите сервис |
| Советник: `ai_unavailable` | Нет доступа к модели, закончились кредиты или нет сети до `api.openai.com`. Проверьте `OPENAI_MODEL` |
| Советник: `ai_timeout` | Модель не ответила вовремя. Увеличьте `OPENAI_TIMEOUT_SECONDS` (до 120) |
| Ключ в `.env` «не применяется» | В терминале осталась переменная `$env:OPENAI_API_KEY` или `$env:OPENAI_MODEL`. Откройте новый терминал |
| `address already in use` | Порт 8000, 8001 или 5173 занят. Остановите старый процесс или смените порт |
| Пустая 3D-сцена | Нужен браузер с WebGL. Открывайте через `http://`, а не `file://`; вид «Список районов» работает без WebGL |

## Ограничения

- Данные районов и эффекты мер синтетические, из датасета кейса. Это не прогноз для реальной Астаны.
- AI не считает и не меняет Score. Цифры в его ответе берутся из расчёта backend. Проверку допустимости плана делает только валидатор.
- Карта, объекты проектов и движение машин — условная визуализация, а не транспортная или градостроительная модель.
- Локальный запуск рассчитан на `127.0.0.1`. Для публичного сервера нужны аутентификация и лимиты на платные AI-запросы.
