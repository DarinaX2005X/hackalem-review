# AI Sana — каталог практических бизнес-задач

MVP по кейсу HackAlem AI. Представитель бизнеса описывает задачу, получает уточняющие вопросы, редактирует карточку и вручную подтверждает публикацию. Студенческие команды видят общий каталог, отправляют предложения, а бизнес сам выбирает или отклоняет каждое из них.

## Что работает

- Черновик задачи, уточняющие вопросы и редактируемая карточка с подтверждением публикации; ИИ помогает разобрать описание и предложить поля карточки.
- Предпросмотр рейтинга и подсказок при редактировании; сохранённую карточку можно изменить после публикации.
- Общий каталог с сортировкой по рейтингу и фильтрами по отрасли и уровню готовности.
- Форма отклика, статус предложения, экран бизнес-решений; бизнес вручную выбирает или отклоняет отклики.
- Пять синтетических описаний для демонстрации, пять карточек задач, пять профилей команд и пять примеров откликов.
- Обмен бизнес-данными через SQLite на сервере. Старые записи из `localStorage` автоматически переносятся при открытии приложения.

## Стек и хранение

- Next.js App Router, React и TypeScript.
- SQLite через `better-sqlite3`. Бизнес-данные и таблицы авторизации находятся в `data/ai-sana.db`; файл создаётся автоматически и исключён из Git.
- Браузер получает задачи, команды и отклики через API. Браузеры, обращающиеся к одному серверу с постоянным диском, видят общие данные.
- Для MVP используется один Node.js-сервер с постоянным локальным диском. Эфемерная файловая система serverless-хостинга и несколько независимых инстансов не подходят для такого SQLite-хранилища без отдельной общей базы.

## Установка и запуск

Требуется Node.js 20.9 или новее.

```bash
npm ci
```

Скопируйте `.env.example` в `.env.local`. В PowerShell:

```powershell
Copy-Item .env.example .env.local
```

Для настоящего AI-уточнения добавьте `OPENAI_API_KEY` только в `.env.local`. Если ключ не задан или API недоступен, используются демонстрационные вопросы. Не отправляйте реальные персональные или конфиденциальные данные в AI.

```bash
npm run dev
```

Откройте <http://localhost:3000>. Перед показом на другом устройстве запустите приложение на сервере, доступном обоим устройствам; `localhost` на телефоне указывает на сам телефон, а не на компьютер.

## Проверочный сценарий для demo

1. На странице «Создать задачу» выберите короткий синтетический пример из списка и нажмите «Найти, чего не хватает».
2. Просмотрите не менее трёх вопросов, ответьте на них и перейдите к карточке.
3. Меняйте, например, поле «Данные и материалы»: рейтинг и подсказки должны меняться сразу. Формулировки «пока не предоставлены» и «нет данных» не получают баллы за доступные данные.
4. Подтвердите публикацию, откройте карточку в каталоге и проверьте рейтинг. Измените её через раздел «Отклики» → «Изменить карточку» и убедитесь, что сохранённый рейтинг и позиция обновились.
5. Откройте каталог в другом браузере или на другом устройстве, отправьте отклик и обновите экран откликов бизнеса. Выберите или отклоните предложение вручную.

Для быстрого показа можно использовать опубликованные синтетические задачи и отклики; конструктор предоставляет пять отдельных синтетических черновых описаний.

## Формула рейтинга

Баллы начисляются за заполненные поля: контекст и потребность — 20 (по 10 за каждое поле), данные и материалы — 20, ожидаемый результат — 15, критерии успеха — 15, ограничения — 10, пользователи — 10, связь с бизнесом — 10 (по 5 за контакт и формат взаимодействия).

- 0–39 — черновик.
- 40–69 — рабочая.
- 70–89 — готовая.
- 90–100 — приоритетная.

Расчёт одинаков на клиенте и сервере, сервер пересчитывает баллы при создании и редактировании карточки. Явные ответы о недоступности сведений, например «нет данных», «не предоставлены», «пока не определили», считаются незаполненными. Это простая проверка известных формулировок, а не полноценная оценка смысла текста; перед публикацией карточку проверяет человек.

## AI и внешние сервисы

`POST /api/clarify` использует серверный `OPENAI_API_KEY`, Responses API и по умолчанию модель `gpt-4.1-mini`. Приложение передаёт исходное описание задачи внешнему API OpenAI и просит вернуть три или более вопросов и предложенные поля карточки по JSON Schema. Ответ валидируется; при ошибке, недоступном API или некорректном JSON возвращается демонстрационный fallback. API-ключ не передаётся в браузер и не должен попадать в GitHub. Маршрут ограничен 12 запросами за 10 минут на клиентский IP.

## Доступ и ограничения MVP

- Для короткого demo вход не требуется, отдельного разделения ролей бизнеса и студентов нет. API карточек и решений доступен клиентам приложения; это не система с производственными правами доступа.
- Основной поток предназначен для синтетических или разрешённых к публикации данных. Не загружайте секреты, персональные и конфиденциальные сведения.
- Ограничение частоты запросов — базовая защита для демонстрации, а не защита от целенаправленного злоупотребления.
- Авторизация и подтверждение контакта существуют отдельно, но не обязательны для demo-сценария и не связывают карточки с владельцем.
- Текущие карточки и отклики в одном серверном SQLite доступны всем клиентам этой демонстрации; для публичной эксплуатации потребуются роли, проверка владения, общая управляемая база данных, резервное копирование и защита от злоупотреблений.
- Успешная отправка отклика не назначает команду автоматически; бизнес может выбрать несколько предложений, отклонить их или оставить без решения.

## Основные маршруты

- `/business/new` — конструктор задачи.
- `/business/tasks/{taskId}/edit` — повторное редактирование опубликованной карточки.
- `/catalog` — общий каталог.
- `/catalog/{taskId}/respond` — отправка предложения.
- `/business/tasks/{taskId}/responses` — решения по откликам.
- `src/features/tasks/scoring.ts` — общая формула рейтинга.
- `src/lib/app-db.ts` — SQLite-хранилище бизнес-данных.
