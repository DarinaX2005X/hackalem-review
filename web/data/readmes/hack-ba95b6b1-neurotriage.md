# Agentic AI: прогноз почасовой выработки ВЭС

## Демо

[Открыть презентацию проекта](https://warm-dodol-16a22b.netlify.app)

## Задача
Прогноз почасовой выработки ветроэлектростанции (2 турбины) на горизонте 24-48 часов, на основе исторических данных и архивных прогнозов погоды.

## Данные
- Исторические данные по 2 турбинам: скорость ветра, температура, нормализованная активная мощность (10-минутные интервалы, март 2023 — январь 2026)
- Тестовый период: 1-28 февраля 2026, прогнозирование выполняется последовательно по дням
- Погодные прогнозы получаются агентом самостоятельно через Open-Meteo Historical Forecast API — используются архивные прогнозы, доступные на момент каждой даты (не фактическая погода задним числом)

## Архитектура
1. **`src/weather_client.py`** — получение архивного прогноза погоды по координатам обеих турбин на конкретную дату
2. **`src/data_loader.py`** — загрузка и агрегация исторических данных ВЭС (10-минутки → часы)
3. **`src/features.py`** — генерация признаков (скорость ветра, куб/квадрат скорости, час, день недели, месяц)
4. **`src/model.py`** — обучение и инференс модели CatBoost (отдельная модель на каждую турбину)
5. **`src/agent.py`** — агентный цикл: получение прогноза погоды → подготовка данных → предсказание → сохранение результата → повтор на следующий день, для всего тестового периода
6. **`src/visualize.py`** — проверка выходных данных на адекватность и визуализация прогноза

## Запуск
\`\`\`bash
pip install -r requirements.txt
python -m src.main
python -m src.visualize
\`\`\`

## Результат

- `forecast_plot.png` — визуализация прогноза
- `models/catboost_T1.cbm`, `models/catboost_T2.cbm` — обученные модели
