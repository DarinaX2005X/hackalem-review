# Wind Power Forecaster

Қазақша/орысша интерфейсі бар жел электр станциясының сағаттық көрсеткіштерін зерттеуге арналған бір файлдық веб-қосымша.

## Іске қосу

`index.html` файлын браузерде ашыңыз. Қосымша Қазақстан уақытымен (UTC+05:00) бүгінгі күнді таңдайды. Күнді, 24/48 сағаттық аралықты, ЖЭС нүктесін және интерфейс тілін өзгертуге болады.

Графиктер үшін Chart.js, карта үшін Leaflet, дизайн үшін Tailwind CDN қолданылады; бұл элементтерге интернет байланысы қажет.

## Дерек көзі мен шектеулер

- Турбина 2-нің 149 499 CSV жазбасы 25 004 тарихи сағатқа біріктіріліп, HTML файлына енгізілген.
- Нақты деректердің мерзімі: **2023-03-11 — 2026-01-31**. CSV файл атауында 2026 жылғы ақпан көрсетілгенімен, оның ішінде ақпан жазбалары жоқ.
- Тарихи күндерде нақты қуат пен жел қисығынан есептелген баға салыстырылады. Бұл тәуелсіз ауа райы болжамымен жасалған бэктест емес.
- Кейінгі күндер, оның ішінде бүгінгі күн, **сценарлық симуляция** ретінде көрсетіледі. Нақты уақыттағы ауа райы немесе өндіріс болжамы ретінде пайдаланбаңыз.
- Сұрақ-жауап бөлімі жергілікті ережелерге сүйенеді; сыртқы AI API қолданылмайды.

## Технологиялар

HTML, JavaScript, Tailwind CSS, Chart.js, Leaflet. Серверлік бөлік пен API кілті қажет емес.
