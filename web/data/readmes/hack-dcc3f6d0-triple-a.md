# AI Sana Challenge Hub

Готовый к демонстрации MVP на Python + Streamlit. Бизнес создаёт и публикует практическую задачу, студенческая команда отправляет предложение, а представитель бизнеса выбирает команду. Данные хранятся в текущей сессии браузера.

## Возможности

- ручное создание и редактирование карточки задачи;
- AI-черновик и AI-рецензия через OpenAI Responses API;
- честно обозначенный локальный demo-режим без API-ключа;
- локальная оценка качества 0–100 и блокировка слабой публикации;
- каталог с поиском, фильтрацией по навыкам и сортировкой;
- отклики команд, защита от повторного отклика и проверка длины полей;
- выбор одной команды и автоматическое закрытие новых откликов;
- адаптивный интерфейс для компьютера и мобильной ширины;
- unit-тесты основной логики и Streamlit AppTest полного сценария.

## Требования

- Python 3.10 или новее;
- интернет нужен только для установки зависимостей и реальных запросов к OpenAI;
- API-ключ не нужен для локальной демонстрации.

## Быстрый запуск в Windows PowerShell

Из папки проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Если команда `py` недоступна, замените её на `python`.

Приложение откроется по адресу `http://localhost:8501`.

## Запуск в macOS / Linux

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python -m streamlit run app.py
```

## Подключение OpenAI API

Откройте `.env` в корне проекта и вставьте ключ после знака `=`:

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-6-astra
```

Файл `.env` уже добавлен в `.gitignore`; не помещайте его в архив или репозиторий. Существующая переменная окружения Windows имеет приоритет над значением из `.env`. Для совместимости приложение также принимает `OPENAI_API_KEY` из `.streamlit/secrets.toml`.

Вариант 2 — переменная окружения PowerShell только для текущего окна:

```powershell
$env:OPENAI_API_KEY = "your-key"
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Модель по умолчанию — `gpt-6-astra`. Её можно переопределить переменной `OPENAI_MODEL`:

```powershell
$env:OPENAI_MODEL = "доступная-вам-модель"
```

Само наличие ключа не считается успешным подключением. После нажатия соответствующей кнопки интерфейс показывает фактический источник конкретного результата: OpenAI API или локальный demo-режим. Локальная генерация детерминирована и нигде не выдаётся за ответ модели. Ошибки API отображаются безопасным сообщением без ключа и внутренних деталей.

## Демонстрационный сценарий

1. Откройте «Создать задачу».
2. Введите черновик для AI-помощника или заполните поля вручную.
3. Примените AI-черновик и при необходимости отредактируйте каждое поле.
4. Нажмите «Оценить качество задачи», изучите рекомендации и запросите рецензию.
5. Опубликуйте карточку с оценкой не ниже 75.
6. Найдите её в каталоге через поиск и фильтры и откройте страницу задачи.
7. Отправьте отклик студенческой команды.
8. В разделе «Отклики для бизнеса» выберите команду.
9. Вернитесь на страницу задачи: новый отклик будет недоступен.

Роли переключаются через верхнюю навигацию без авторизации. Для непрерывной демонстрации используйте одну вкладку: перезапуск сервера или новая вкладка создают новую сессию.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты находятся в `tests/` и покрывают оценку, публикацию, повторное нажатие, локальный AI-режим, валидацию отклика, повторный отклик, выбор команды и полный Streamlit-сценарий.

## Структура

- `app.py` — интерфейс, навигация и состояние Streamlit;
- `ai_assistant.py` — OpenAI Responses API и локальный demo-режим;
- `utils.py` — оценка, публикация, отклики и выбор команды;
- `tests/` — unit- и Streamlit AppTest-тесты;
- `.streamlit/config.toml` — тема и серверные настройки;
- `requirements.txt` — зависимости запуска и тестов.
