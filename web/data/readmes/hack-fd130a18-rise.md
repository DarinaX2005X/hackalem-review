# 🎯 EventMatch AI (#79-lite)

Сервис подбора event-подрядчиков в Казахстане: строгие фильтры, детерминированные баллы и объяснения от OpenAI.

## 💡 Пайплайн

1. **LLM-парсер (`ai/parse_query.py`):** OpenAI извлекает параметры из текста; пользователь проверяет форму перед поиском.
2. **Фильтры (`pipeline/filters.py`):** Город, категория, календарь, бюджет, формат, часы и язык.
3. **Ранжирование (`pipeline/ranking.py`):** Фиксированная формула баллов и стабильная сортировка. Эмбеддинги в основной подбор не включены.
4. **Объяснения (`ai/polish.py`):** После `recommend()` интерфейс вызывает LLM для выбранных карточек. Фильтры, баллы и порядок не меняются.

Объяснения генерируются параллельно с таймаутом 5 секунд, без автоматических повторов.
Проверяются пропущенные и добавленные числа; при ошибке используется исходный шаблон и показывается причина.
Числовая проверка не гарантирует отсутствие любых смысловых ошибок: исходные факты доступны в раскрывающемся блоке карточки.
Успешные объяснения кэшируются в памяти по фактам, запросу, модели и инструкции. Кэш очищается после перезапуска.

## 🚀 Быстрый запуск

Нужен Python 3.11 или новее. Команды выполняются из корня проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Создайте `.env` рядом с README по образцу `.env.example`, указав свой `OPENAI_API_KEY`.
По умолчанию используется `gpt-4o-mini`; модель можно задать через `OPENAI_MODEL`.
Ключ автоматически читается сервером из `.env`, не отправляется браузеру и не должен попадать в Git.
Запрос и факты показанных карточек отправляются в OpenAI; нужен доступный баланс API.

```bash
python -m streamlit run ui/app.py
```

Откройте http://localhost:8501. Введите запрос, нажмите «Разобрать запрос с ИИ», проверьте форму и запустите подбор.
Бейдж «Объяснение от ИИ» означает успешный ответ LLM. «Объяснение по шаблону» сопровождается причиной возврата к шаблону.
Без доступного API можно заполнить форму вручную; подбор продолжит работать с шаблонными объяснениями.

Пример: «Нужен ведущий на свадьбу в Алматы 7 октября 2026, бюджет 1,2 млн, на 5 часов, на русском».
Календари датасета покрывают 23.09.2026–31.12.2026. В запросе без года используется 2026.

Проверки без вызова OpenAI:

```bash
python -m tests.test_scenarios
python test_pipeline.py
```
