# Анализ организационной структуры и функций

Прототип для автоматизированного сравнения двух версий организационных документов — «До» и «После».

Система извлекает текст из документов, сопоставляет функции и формирует аналитическое заключение с указанием источников. Решение помогает находить изменения функций, потенциальные потери, дублирование, пересечения ответственности и изменения подразделений.

## Что реализовано

- загрузка документов версий «До» и «После»;
- поддержка DOCX, PDF, XLSX и XLSM;
- извлечение текста и фрагментов документов;
- определение подразделений и функций;
- сопоставление функций между версиями документов;
- поиск изменений функций;
- выявление потенциально потерянных функций;
- выявление возможного дублирования и пересечения ответственности;
- отображение источника каждого наблюдения;
- аналитическая сводка результатов;
- экспорт заключения в Markdown;
- интерфейс на Streamlit;
- автоматические тесты основного сценария.

## Как работает решение

1. Пользователь загружает исходную версию документа в блок «До».
2. Пользователь загружает обновлённую версию в блок «После».
3. Система извлекает текст и структурирует фрагменты документов.
4. Правила анализа определяют функции и подразделения.
5. Функции версий «До» и «После» сопоставляются по текстовому сходству.
6. Система формирует наблюдения об изменениях, потерях, дублировании и пересечениях.
7. Для результатов отображаются исходные фрагменты документов.
8. Пользователь может просмотреть аналитическое заключение и скачать его в Markdown.

## Технологии и архитектура

- Python
- Streamlit
- python-docx
- PyMuPDF
- openpyxl
- pytest

Основные компоненты:

- `analyzer/extractors.py` — извлечение данных из документов;
- `analyzer/findings.py` — анализ функций и формирование наблюдений;
- `analyzer/matching.py` — сопоставление функций;
- `analyzer/models.py` — модели данных;
- `analyzer/report.py` — формирование аналитического заключения;
- `app.py` — пользовательский интерфейс Streamlit.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
streamlit run app.py
```

После запуска откройте локальный адрес, указанный Streamlit в терминале.

## Проверка

Для запуска автоматических тестов:

```bash
pytest
```

Основной пользовательский сценарий:

1. Загрузить документ «До».
2. Загрузить документ «После».
3. Нажать «Запустить анализ».
4. Проверить найденные изменения и их источники.
5. Просмотреть сопоставление функций и аналитическое заключение.

## Данные и внешние сервисы

Документы обрабатываются локально приложением. Текущая версия прототипа не требует внешнего AI API для выполнения основного анализа.

## Ограничения

- Определение подразделений и функций основано на эвристических правилах и зависит от структуры исходных документов.
- В сложных или нестандартно оформленных документах название подразделения может быть определено неточно.
- Результаты автоматического анализа носят рекомендательный характер и требуют экспертной проверки.
- Старые форматы `.doc` и `.xls` необходимо предварительно сохранить в современном формате.
- Сопоставление функций основано на текстовом сходстве и не является полноценным семантическим анализом.
