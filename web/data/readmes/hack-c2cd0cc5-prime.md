# hack-c2cd0cc5-prime
Hackathon team repository for Prime
1. Что решает продукт
Это веб-витрина «Электрокомплект» с помощником Хелпи. Она помогает подобрать электротехнические товары по названию, артикулу или описанию задачи, просмотреть цену, характеристики и остатки по складам, собрать позиции в корзину и скачать список для заказа. Также можно задать вопросы о доставке и оплате и загрузить файл для поиска позиций.
2. Как запустить
Для демонстрации достаточно открыть файл EKT-Helpy-preview.html в современном браузере двойным кликом. Он содержит автономный предпросмотр с сохранённым каталогом, ценами и учебной корзиной.
Для полноценной работы нужен отдельный сервер проекта: интерфейс обращается к API /api/products, /api/cart, /api/chat, /api/attachments и др. Сам серверный код и инструкция его запуска в приложенном HTML отсутствуют.
3. Используемые технологии
   - Один самодостаточный HTML-файл: HTML5, CSS и нативный JavaScript.
   - Нет подключённых внешних JS-библиотек или сборщика; интерфейс реализован на vanilla JS.
   - fetch для запросов к серверному REST API.
   - localStorage для избранного в автономном режиме.
   - FileReader для прикрепления файлов.
   - Встроенные данные каталога (EKT_BOOTSTRAP) для режима предпросмотра.
4. Как проверить решение
5. Открыть HTML-файл в браузере.
6. Проверить поиск: например, «автомат 16А» или «кабель ВВГ 3×2,5».
7. Открыть карточку товара и убедиться, что видны характеристики, цена и остатки.
8. Открыть Хелпи и отправить запрос на подбор товара.
9. Добавить товар в корзину, изменить количество, удалить позицию и скачать список заказа.
10. Проверить избранное и переключение города.
11. Для проверки интеграционной версии запустить сервер, затем убедиться в ответах API, актуальности каталога/остатков и обработке чата и вложений.
