# NAQTY — идеядан нақты іске

Қазақ тіліндегі жұмыс істейтін MVP. Сары, сұр және хаки түстері, мобильді интерфейс, бизнес пен студенттік командаларға бөлек рөлдер. Жергілікті Node.js/SQLite және онлайн Cloudflare Worker/D1 нұсқалары бар.

## VS Code-та іске қосу

1. Осы `NAQTY` қалтасын Visual Studio Code арқылы ашыңыз.
2. **Node.js 24 немесе жаңарақ** нұсқасы қажет.
3. VS Code терминалында орындаңыз:

```sh
npm start
```

4. Браузерде **http://localhost:3000** ашыңыз. Тоқтату: терминалда `Ctrl+C`.

Сыртқы npm пакеттері қажет емес. `npm install` орындамай-ақ жұмыс істейді. F5 арқылы серверді дебаг режимінде іске қосуға болады. Әзірлеу кезінде автоматты қайта іске қосу: `npm run dev`.

## Қамтылған мүмкіндіктер

- Email / құпиясөзбен тіркелу, кіру, шығу. Құпиясөздер scrypt арқылы хэштеледі; HttpOnly cookie сессиялары.
- Кіргеннен кейін жас, тәжірибе деңгейі және бұрын бизнес бастағаны сұралады.
- Бизнес өкілі және студенттік команда рөлдері; командада атау, қызығушылық, дағды және технология өрістері.
- Жаңадан бастаушыға стандартты, орта деңгейге күрделі, сарапшыға дайын жобалар ұсынылады. Каталогтағы барлық жарияланған тапсырма бәріне ашық.
- Сарапшыларға 3 жұмыс істейтін бастапқы прототип бар: оқу порталы, күндердің қабаттасуын тексеретін брондау жүйесі және іздеу/себеті бар сауда алаңы. «Дайын жоба» карточкасынан ашып, бір HTML файл түрінде кодын жүктеуге болады. Бұл шағын үлгілер деректерді тек браузерде сақтайды және нақты тапсырыс/төлем қабылдамайды.
- Еркін қажеттілік → контекстке бейімделетін 6 сұрақ → өңделетін 10 өрісті карточка → қолмен растау → жариялау.
- Жеке нұсқаларды сақтау, жарияланған карточканы өңдеу, 0–100 рейтинг, балдардың толық бөлінісі, жетіспейтін мәліметтер. Рейтинг браузерде бірден, серверде сақтағанда қайта есептеледі.
- Каталог: рейтинг бойынша сұрыптау, мәтіндік іздеу, тақырып, дайындық және тапсырма түрі бойынша сүзу.
- Шектеусіз ұсыныстар: идея, жоспар, мерзім, http(s) прототип сілтемесі. Бизнес бір, бірнеше немесе ешбір команданы қолмен таңдайды; қабылдамау және қайта қарастыру әрекеттері бар. Автоматты тағайындау жоқ.
- 3 шағын курс, 7 мәтіндік сабақ және практикалық жаттығулар; аяқтау прогресі базаға сақталады.
- Қаржы калькуляторы: кіріс, шығын, салық мөлшерлемесі, комиссия, салық базасын таңдау, таза пайда, маржа, диаграмма. Әдепкі 3% және 2% — есептік мысал, ресми мөлшерлеме емес.
- NAQTY көмекші: сервер жағынан Google Gemini API-мен байланысады. Кілт жоқ болса ғана жергілікті ережелер режимінде жұмыс істейді; Gemini қатесі жасырылмайды. Кілт браузерге және Git-ке жіберілмейді. Соңғы 8 хабарлама контексті, жауап күту индикаторы және сұрау лимиттері бар.

## Демо және деректер

Бастапқы база автоматты түрде **9 синтетикалық тапсырма, 4 команда және 6 ұсыныспен** толтырылады. Техникалық тапсырмада нақты ең төменгі сан берілмегендіктен осы көлем алынды. Демо ұсыныстардағы example.com сілтемелері нақты прототип емес және интерфейсте белгіленген.

| Рөл | Email | Құпиясөз |
|---|---|---|
| Бизнес | business@naqty.demo | Naqty2026! |
| Команда | team@naqty.demo | Naqty2026! |

Тіркелу бетінде екі демо батырма бар. Өзіңіздің жаңа тіркелгіңізді де жасауға болады. Деректер `data/naqty.sqlite` файлында сақталады; сервер қайта іске қосылса да жоғалмайды. Демо тіркелгілер жергілікті көрсетуге арналған.

## Тексеру сценарийі

1. Бизнес ретінде тіркеліп, бастапқы сауалнаманы толтырыңыз.
2. «Жаңа тапсырма» → сипаттама → 6 сұраққа жауап → карточканы өңдеу.
3. Рейтинг пен жетіспейтін өрістерді тексеріңіз, байланыс пен кері байланыс форматын енгізіңіз.
4. Растау белгісін қойып, жариялаңыз.
5. Профильден шығып, команда ретінде тіркеліңіз; команда мәліметтерін толтырыңыз.
6. Каталогтан тапсырманы тауып, идея, жоспар, мерзім және прототип сілтемесімен ұсыныс жіберіңіз.
7. Бизнес ретінде қайта кіріп, «Команда ұсыныстары» бөлімінде таңдау жасаңыз.
8. Бетті жаңартып, шешімнің және сабақ прогресінің сақталғанын тексеріңіз.

```sh
npm test
```

Тесттер бөлек уақытша SQLite базасы мен 3099 портын пайдаланады. Рейтинг, калькулятор, тіркелу, профиль, жеке нұсқа, жариялау, авторлық құқық, бірнеше ұсыныс/таңдау, сессия және оқу прогресін тексереді. Негізгі демо база өзгермейді.

## Файлдар

- `server.mjs` — Node HTTP API, сессиялар, SQLite, рөлдік тексерулер.
- `lib.mjs` — ортақ рейтинг, сұрақтар және қаржы есептеуі.
- `seed.mjs` — синтетикалық тапсырмалар және сабақ мазмұны.
- `public/` — интерфейс, стильдер, бренд белгісі.
- `tests/core.test.mjs` — автоматты интеграциялық және логикалық тесттер.

## Онлайн нұсқа және Gemini

Хостинг жобасы `.openai/hosting.json` файлында тіркелген. `npm run build` интернетсіз орындалып, `dist/server/index.js` файлын жасайды. Онлайн нұсқа D1 базасындағы ортақ деректермен жұмыс істейді. Жергілікті база автоматты түрде интернетке көшірілмейді.

`GEMINI_API_KEY` — Sites runtime баптауындағы құпия мән. `GEMINI_MODEL` — модель атауы; әдепкісі `gemini-3.8-flash`. Кілтті ашық кодқа немесе `public/` қалтасына жазбаңыз. Жергілікті іске қосу үшін `.env.example` үлгісінен жеке `.env` жасап, `node --env-file=.env server.mjs` орындауға болады. `.env` Git-тен шығарылған.

Көмекші Google Interactions API-ге сұрақ пен соңғы 8 хабарламаны жібереді, `store:false` қолданады. Әр пайдаланушыға сағатына 20, бүкіл сайтқа күніне 100 ИИ сұрауы шектелген. Бір жауап 900 токенге дейін. API кілті қабылданбаса, лимит таусылса немесе сервис жауап бермесе, интерфейс нақты қате көрсетеді. Модельдің жауабын маңызды шешімдер алдында тексеріңіз.

Онлайн демоға арналған тіркелгілер ортақ. Жеке тапсырмалар үшін өз тіркелгіңізді жасаңыз. Email растау және құпиясөзді қалпына келтіру бұл MVP-де жоқ. Суреттер Unsplash-тан, қаріп Google Fonts-тан жүктеледі.
