# Meeting Notes — локальные протоколы встреч

Локальное приложение для записи Google Meet/Zoom, расшифровки аудио, подготовки
черновика протокола, ручной проверки задач и экспорта Word. В интерфейсе
сохранены полезные идеи проекта `hackalem`: строгая проверка ответа модели,
цитата-основание для каждой автоматически предложенной задачи, редактирование
таблицы и создание DOCX только по нажатию пользователя.

## Приватность

- Аудио расшифровывает локальная модель Faster-Whisper.
- Текст анализирует локальная модель Ollama.
- Адрес Ollama ограничен `localhost`; удалённые облачные API запрещены кодом.
- При первой настройке модели скачиваются на компьютер. Звук встречи и транскрипт
  наружу не отправляются.
- Сервис привязан к `127.0.0.1`; не публикуйте его в интернете и сообщите
  участникам о записи, получив необходимое согласие.

> В репозитории исходного кейса есть запрет на отправку рабочих данных во внешнее
> облако. Поэтому здесь отключены OpenAI/Anthropic API и ключи из старого `.env`
> не используются.

## Установка на Windows

1. Установите Python 3.11 или новее.
2. Установите [Ollama](https://ollama.com/download) и запустите приложение.
3. Дважды щёлкните `setup_models.bat` или выполните `ollama pull qwen2.5:3b`.
   Скачивание весов модели может занять несколько гигабайт.
4. Запустите `start.bat` двойным щелчком или из PowerShell в папке проекта:

   ```powershell
   .\start.bat
   ```

5. Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Статус локальных
   компонентов доступен на [http://127.0.0.1:8000/health](http://127.0.0.1:8000/health).

При первой обработке Faster-Whisper загрузит модель `small` (около 500 МБ) в
папку `models/`. Это загрузка весов модели; аудио в интернет не передаётся.
Затем обработка работает локально. Локальная модель текста должна быть заранее
доступна в Ollama.

Для компьютера с небольшой видеопамятью выбрана модель `qwen2.5:3b`. Если она не
загружается, в `.env` можно заменить `OLLAMA_MODEL` на `qwen2.5:1.5b`, выполнить
`ollama pull qwen2.5:1.5b` и перезапустить приложение. Для повышения качества
распознавания можно выбрать `WHISPER_MODEL=medium`, но он требует больше памяти
и работает медленнее.

## Запись Meet или Zoom

1. Сообщите участникам о записи и получите согласие.
2. Откройте приложение и заполните название, дату, язык аудио и язык протокола.
3. Нажмите «Начать запись».
4. В окне браузера выберите вкладку Google Meet и включите «Передавать звук
   вкладки». Для настольного Zoom выберите экран/окно и включите системный звук.
5. Оставьте включённым микрофон, если нужно записать свой голос.
6. После встречи нажмите «Остановить запись», дождитесь локальной обработки.
7. Проверьте сводку и предложенные задачи, при необходимости исправьте таблицу,
   затем скачайте Word.

Также можно загрузить готовый аудио- или видеофайл: MP3, WAV, M4A, MP4, WebM,
OGG или FLAC размером до 25 МБ.

## Что распознаётся

В расшифровку попадают все голоса, которые реально слышны в выбранном источнике
записи. Для удалённых участников обязательно передавайте звук вкладки/системы;
микрофонный звук сам по себе не содержит речь из Meet или Zoom. Если голосов нет
в исходном файле, восстановить их нельзя.

Локальная сборка пока не выполняет акустическую диаризацию: она не ставит метки
`A/B` по голосам и не распознаёт человека биометрически. Имена участников
добавляются только если они явно названы в речи. Транскрипт разделён по временным
фрагментам; задачи снабжаются цитатами из распознанного текста. Перед утверждением
проверьте, что цитата действительно подтверждает задачу.

## Хранение и ограничения

- Исходный аудиофайл хранится во временном файле только во время обработки и
  удаляется после неё.
- Результаты задач хранятся в памяти и пропадут при перезапуске приложения.
- Один файл — до 25 МБ; транскрипт — до 60 000 символов. Автоматического деления
  длинных записей пока нет.
- Это локальный демонстрационный продукт без аккаунтов, базы данных, аудита и
  коллективного доступа. Не запускайте сервер с доступом извне.

## Структура

- `main.py` — локальный FastAPI-сервис, загрузка аудио, задачи и экспорт.
- `utils.py` — локальное распознавание, Ollama, схемы и проверка цитат.
- `docx_generator.py` — документ Word с решениями, задачами и основаниями.
- `static/index.html` — браузерная запись и интерфейс ручной проверки.
- `setup_models.bat` — загрузка модели для Ollama после установки Ollama.
- `.env.example` — только локальные настройки модели; секретные ключи не нужны.

## API

- `GET /health` — статус Faster-Whisper и локальной Ollama-модели.
- `POST /transcribe` — загрузить аудио и вернуть `task_id`.
- `GET /transcribe/{task_id}` — получить состояние/результат обработки.
- `POST /transcribe/{task_id}/document` — создать DOCX из проверенных пользователем
  значений.
- `GET /docs` — схема локального API.
