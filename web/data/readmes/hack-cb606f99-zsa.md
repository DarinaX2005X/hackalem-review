# Task Hub

MVP по кейсу HackAlem AI / AI Sana: бизнес превращает описание проблемы в подтверждённую карточку с рейтингом готовности, команды предлагают решения, а бизнес выбирает исполнителей вручную.

## Возможности

- Описание → минимум 3 уточняющих вопроса → редактируемая карточка → ручное подтверждение и публикация.
- Рейтинг 0–100 с расшифровкой баллов и подсказками о недостающих сведениях.
- Каталог с поиском, сортировкой и фильтрами; отклики с идеей, планом, сроком и необязательной ссылкой на прототип.
- Выбор одной, нескольких или ни одной команды.
- Этапы работы: отчёт команды → проверка бизнеса → подтверждение или доработка. За подтверждённый этап — 10 баллов команды, отдельно от рейтинга задачи.

## Запуск

Нужны Node.js 22, pnpm 11 и Git. Команды для PowerShell:

```powershell
git clone https://github.com/BAITC-Hacks/hack-cb606f99-zsa.git
cd hack-cb606f99-zsa
corepack enable
pnpm install --frozen-lockfile
if (-not (Test-Path .env.local)) { Copy-Item .env.example .env.local }
pnpm dev
```

На macOS/Linux вместо строки с `Copy-Item`: `test -f .env.local || cp .env.example .env.local`.

Открыть [localhost:3000](http://localhost:3000). Фронтенд и API запускаются одним процессом, отдельная БД не нужна.

По умолчанию `AI_PROVIDER=mock`: AI работает по локальным шаблонам без внешних запросов. При этом `NEXT_PUBLIC_DATA_MODE=api` оставляет задачи, отклики и этапы на настоящем backend.

Для внешнего AI в `.env.local` задайте `AI_PROVIDER=openai`, `OPENAI_API_KEY` и `OPENAI_MODEL`, затем перезапустите сервер. Остальные настройки — в [.env.example](.env.example). Ключи не должны иметь префикс `NEXT_PUBLIC_` или попадать в Git.

При первом обращении к API данных создаётся `data/db.json`: 5 карточек с исходными описаниями, 5 команд и 5 откликов. Четыре задачи опубликованы, одна — черновик. Существующая база не сбрасывается; путь задаётся через `DATA_FILE_PATH`. Локальная база исключена из Git.

## Архитектура

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Zod, OpenAI SDK, Vitest.

```text
src/app/              Страницы; app/api — HTTP API
src/components/       Интерфейс бизнеса и команд
src/lib/client/       Клиент API и автономный деморежим
src/server/           AI, бизнес-правила, рейтинг и JSON-хранилище
src/shared/           Общие схемы данных и веса рейтинга
docs/                 Контракты API и подробная документация
```

Интерфейс обращается к API; сервер валидирует запросы, рассчитывает рейтинг и сохраняет данные. AI готовит черновик, но не публикует задачи и не выбирает команды. Извлечённые сведения проверяются по исходному тексту; итог редактирует и подтверждает человек.

[Промпты](src/server/ai/prompts.ts), [схемы входа и выхода](src/shared/contracts.ts) и [форматы запросов](docs/API.md). При сбое AI используется явно обозначенный шаблонный fallback; при `AI_FALLBACK_TO_MOCK=false` API возвращает ошибку 502. Карточку можно заполнить вручную.

## Формула рейтинга

Рейтинг задачи — сумма весов заполненных и подтверждённых человеком показателей. Каждый показатель даёт полный вес или 0.

| Показатель | Баллы |
| --- | ---: |
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Связь с бизнесом | 10 |
| **Всего** | **100** |

Для «Связи с бизнесом» нужны подтверждённые контакт и формат взаимодействия. Редактирование поля в интерфейсе снимает его подтверждение; после повторного подтверждения рейтинг пересчитывается. Рейтинг оценивает полноту сведений, а не их истинность.

Уровни: **0–39** — черновик, **40–69** — рабочая, **70–89** — готовая, **90–100** — приоритетная. Это уровни готовности, а не статусы публикации. Веса и границы заданы в [src/shared/scoring.ts](src/shared/scoring.ts).

## Правила каталога

- Все опубликованные задачи доступны всем командам независимо от рейтинга.
- По умолчанию выше задачи с большим рейтингом; при равенстве — более новые. Есть поиск, фильтры по теме и готовности, сортировка по новизне.
- Для публикации нужны название, его ручное подтверждение и согласие на публикацию. Низкий рейтинг не блокирует публикацию или отклик.
- Число откликов не ограничено. Решения принимает бизнес, автоматического назначения нет.
- Архивные задачи исключаются из каталога; история откликов и подтверждённого прогресса сохраняется.

## Проверка

```powershell
pnpm check
pnpm test:smoke
```

`check` выполняет lint, проверку типов, тесты и production-сборку. `test:smoke` использует эту сборку и временную базу: проверяет HTTP-сценарий и сохранение данных после перезапуска. Оба запуска обходятся без платных AI-запросов и не меняют рабочую базу.

Последний полный прогон 23.09.2026: **223 теста, сборка и HTTP smoke прошли**. Отдельная платная проверка AI — `pnpm test:ai`; [сценарии и результаты](docs/AI-QUALITY.md). [Health](http://localhost:3000/api/health) проверяет хранилище, но не доступность внешнего AI.

### Тестовые сценарии

1. **Сквозное демо:** «Создать задачу» → пример «Кофейня» → ответы на вопросы → карточка → проверка и подтверждение полей → публикация → отклик команды → принятие или отклонение бизнесом.
2. **Пересчёт:** подтвердить заполненный контекст — получить 20 баллов; изменить его — снять подтверждение и соответствующие баллы; подтвердить снова.
3. **Низкий рейтинг:** опубликовать задачу с рейтингом 20/100, найти в каталоге и отправить предложение.
4. **Защита данных:** публикация без подтверждённого названия не проходит; устаревшая версия при сохранении возвращает конфликт, введённый текст остаётся в форме.
5. **Прогресс:** выбранной команде создать этап, сдать отчёт, вернуть на доработку, сдать повторно и подтвердить. Баллы появляются только после подтверждения; повторное подтверждение не начисляет их снова.

## Ограничения MVP

Авторизации и ограничения частоты AI-запросов нет: роли демонстрационные. Создание команды доступно через API, в интерфейсе выбираются готовые профили. JSON-хранилище рассчитано на один локальный сервер с постоянным диском. Не открывайте экземпляр с приватными данными или платным AI-ключом в интернет без защиты доступа.

Чат, уведомления, загрузка файлов, рекомендации по навыкам и production-инфраструктура не реализованы и не обязательны для кейса.
