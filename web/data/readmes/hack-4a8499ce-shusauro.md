# Qala — «Аким на 5 часов»

Игровой MVP для HackAlem AI: выберите пять городских или районных мер и увидьте детерминированный расчёт Astana Quality of Life Score для пяти районов Астаны. Расчёт выполняет Python backend; OpenAI может только объяснять готовые результаты.

## Что работает

- Бюджет 100 условных единиц, пять окончательных решений. После каждого решения появляется газетная реакция; после пятой игрок продолжает к итоговому расчёту.
- Городские меры применяются ко всем районам. Для районной меры сначала выберите район на карте.
- Каталог показывает стоимость, направление, тип, лаг, полный эффект, потенциальные синергии и несовместимости.
- Валидатор запрещает повтор меры, превышение бюджета, больше двух решений одного направления и конфликтующие решения.
- Backend учитывает лаг в горизонте 8 кварталов, синергии, ограничение показателей диапазоном 0–100, доли населения, слабейший район и критические показатели ниже 40.
- Один итоговый аналитический экран показывает Score, показатели «до / после», изменение по каждому району и выбранный план.
- AI Media Reaction Engine получает проверенные backend-факты и создаёт негативный газетный выпуск после каждого решения. Final AI Analyst получает готовый детерминированный результат и формирует один аналитический экран. Без OPENAI_API_KEY используются краткие детерминированные редакционные тексты и аналитическая сводка.
- Аккаунты и база данных не нужны. Данные синтетические.

## Требования

- Node.js 20+
- Python 3.11+

## Запуск в Windows PowerShell

Из корня репозитория откройте два терминала.

Терминал 1 — backend:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r backend\requirements.txt
Copy-Item backend\.env.example backend\.env
uvicorn backend.main:app --reload --port 8000
```

Терминал 2 — frontend:

```powershell
npm install
npm run dev
```

Откройте <http://localhost:3000>. API доступно на <http://localhost:8000>; описание endpoint'ов FastAPI — <http://localhost:8000/docs>.

Чтобы включить AI-хронику, добавьте `OPENAI_API_KEY` в `backend/.env` и перезапустите backend. Ключ хранится только на сервере и не передаётся в браузер. Для симуляции и расчёта результата он не нужен.

## Формула

Реализованный эффект меры равен `полный эффект × (8 − lag) / 8`. Синергия добавляется отдельно и не масштабируется лагом. Для каждого района рассчитывается взвешенная оценка по десяти показателям; городской балл — среднее по долям населения. Итог:

```text
Score = 0.7 × городской балл + 0.3 × балл самого слабого района − критические показатели
```

Критическим считается каждый показатель района со значением строго ниже 40. Исходный Score в наборе данных — 52.56.

## Структура

- `app/` — Next.js, React, TypeScript, Tailwind CSS.
- `backend/engine.py` — набор синтетических данных, правила проверки и детерминированный движок.
- `backend/main.py` — FastAPI: dataset, preview, simulation, газетная реакция и итоговый анализ.
- `backend/media_analysis.py` — детерминированный сбор проверяемых фактов и media angles для редакционного narrative layer.
- `design/` — исходные черновики интерфейса.

Карта схематическая и предназначена для симуляции, а не для навигации или отображения точных административных границ.
