# TaskReady — AI Sana / Prompt Chiefs

## Описание

Представителям бизнеса трудно описать задачу для студентов так, чтобы по ней можно было сразу начать работу. Студенческим командам трудно понять, какие задачи уже готовы.

TaskReady помогает бизнесу превратить черновое описание в полную карточку задачи. Сервис оценивает, насколько полно заполнена карточка (рейтинг 0–100), и публикует её в открытом каталоге. Студенческие команды сами выбирают задачи и откликаются. Бизнес вручную принимает или отклоняет отклики.

**Для кого:** представители бизнеса и студенческие команды (кейс хакатона AI Sana).

## Что реализовано

- **Конструктор задачи.** Свободное описание, 5 примеров черновиков, демо-задача, редактируемая карточка из 11 полей, ручное подтверждение публикации.
- **AI-диагностика задач.** Три уточняющих вопроса о недостающих сведениях на языке интерфейса. Ответы человека копируются в карточку без изменений.
- **Прозрачность AI.** Блок «Как работает AI-диагностика» показывает режим, промпт, JSON-запрос и JSON-ответ.
- **Рейтинг готовности 0–100.** Расшифровка по 7 критериям, подсказки к каждому недостающему критерию, пересчёт при редактировании.
- **4 уровня готовности:** Черновик, Рабочая, Готовая, Приоритетная.
- **Каталог.** Сортировка по рейтингу, фильтры по отрасли и уровню. Приоритетные задачи выделены, черновики помечены «Требует уточнения».
- **Рекомендации командам.** Задачи от 40 баллов, отрасль которых совпадает с интересами команды. Каталог при этом не ограничивается.
- **Отклики команд.** Идея, план, срок и ссылка на прототип, число откликов не ограничено.
- **Решение бизнеса.** Ручные «Принять» и «Отклонить»: можно выбрать несколько команд или ни одной, автоматического назначения нет.
- **Подтверждённый прогресс.** После подтверждения этапа команда получает +10 баллов, один раз за отклик. После этого решение окончательное.
- **Интерфейс.** Русский, казахский и английский языки; светлая и тёмная тема.

## Как работает решение

1. Бизнес вводит краткое описание или загружает пример.
2. AI-диагностика определяет пустые поля и задаёт 3 вопроса.
3. Ответы переносятся в карточку, бизнес дополняет и редактирует поля.
4. Рейтинг пересчитывается, подсказки показывают, что поднимет балл.
5. Бизнес подтверждает публикацию, и задача попадает в каталог на место по рейтингу.
6. Команда выбирает задачу (сама или через рекомендации) и отправляет отклик.
7. Бизнес сравнивает отклики и вручную принимает или отклоняет их.
8. После выполненного этапа бизнес подтверждает его, и команда получает +10 баллов.

## Технологии

- **Язык и фреймворки:** TypeScript, React 19, Vite 8.
- **Тесты:** встроенный `node:test` (Node.js 22.16+).
- **AI по умолчанию:** детерминированная локальная заглушка в браузере (`src/lib/ai.ts`).
- **AI опционально:** локальная модель `qwen2.5:3b` через [Ollama](https://ollama.com). Работает бесплатно и без API-ключа, подключается через прокси `server/task-doctor.mjs` на Node.js без зависимостей.
- **Хранение:** localStorage браузера.

## Архитектура

| Компонент | Назначение |
|---|---|
| `src/App.tsx` | Экраны: конструктор, каталог, отклики |
| `src/types/domain.ts` | Модель данных: задача, команда, отклик |
| `src/lib/scoring.ts` | Чистая формула рейтинга и уровней |
| `src/lib/ai.ts` | AI-адаптер: локальная заглушка, вызов внешнего endpoint, проверка ответа, fallback |
| `src/lib/recommendations.ts` | Рекомендации задач по интересам команды |
| `src/lib/proposals.ts` | Правила решений бизнеса и прогресса |
| `src/lib/storage.ts` | Сохранение в localStorage, восстановление после повреждённых данных |
| `src/lib/i18n.ts` | Переводы (ru / kk / en) |
| `src/components/` | `TaskEditor`, `ScorePanel`, `AiContract`, `DemoJourney`, `Preferences` |
| `src/data/seed.ts` | Синтетические демо-данные |
| `server/task-doctor.mjs` | Опциональный локальный прокси: браузер → прокси → Ollama |
| `tests/domain.test.mjs` | Автотесты бизнес-логики |

Как части связаны между собой. Браузер вызывает прокси, только если задана переменная `VITE_TASK_DOCTOR_ENDPOINT`. Любая ошибка — HTTP, неверный JSON, неизвестное поле, меньше 3 вопросов или таймаут 20 секунд — переключает сайт на локальные вопросы.

## Установка и запуск

Нужны Node.js 22.16+ и npm.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

Другие команды:

```sh
npm test          # автотесты
npm run build     # проверка TypeScript и сборка в dist
npm run preview   # запуск собранной версии
```

### Локальная AI-модель (необязательно, бесплатно)

```sh
# 1. Установить Ollama: https://ollama.com (Windows: winget install Ollama.Ollama)
ollama pull qwen2.5:3b

# 2. Запустить прокси (терминал 1)
npm run ai-proxy

# 3. Скопировать .env.example в .env.local и перезапустить сайт (терминал 2)
npm run dev
```

Без Ollama сайт полностью работает на локальной заглушке. Другую модель можно выбрать переменной `TASK_DOCTOR_MODEL`.

## Как проверить решение

1. «Сбросить демо-данные» → «Создать задачу» → «Загрузить демо с анализом отзывов». Рейтинг 0.
2. «AI-диагностика задач». Ответить:
   - потребность — «Выявлять повторяющиеся жалобы и передавать их ответственным сотрудникам»;
   - данные — «Обезличенный CSV с 500 отзывами и категориями за последний месяц»;
   - результат — «Веб-прототип группировки отзывов с фильтром по категории».

   Нажать «Применить ответы к карточке»: рейтинг 55. Раскрыть «Как работает AI-диагностика».
3. Заполнить поля:
   - «Пользователи» — «Руководитель клиентской поддержки»;
   - «Критерии успеха» — «Не менее 80% верных категорий на 100 контрольных отзывах»;
   - «Ограничения» — «Локальный прототип за две недели без персональных данных»;
   - «Контакт» — `owner@example.com`;
   - «Формат взаимодействия с бизнесом» — «Две консультации в неделю, письменная обратная связь в течение суток».

   Рейтинг 100. «Подтвердить и опубликовать» → «Опубликовать задачу».
4. В каталоге в «Рекомендациях для команды» выбрать Nova Stack, открыть новую задачу и отправить отклик со ссылкой вида `https://example.com/...`.
5. «Отклики» → «Принять».
6. Ввести описание выполненного этапа и подтвердить: +10 баллов, кнопки решения исчезают.
7. Перезагрузить страницу: данные сохранены.

Дополнительно можно проверить:
- текст «ааааааааааааааа» в «Ограничениях» не даёт баллов;
- критерии успеха без цифр не засчитываются;
- задача с рейтингом 0 видна в каталоге и принимает отклики.

## Данные и интеграции

- **Данные:** синтетические, в `src/data/seed.ts` — 5 черновиков, 5 карточек, 5 команд, 5 откликов на русском. Ссылки на прототипы (`example.com`) демонстрационные.
- **Внешние API и облачные сервисы не используются.** Опциональная интеграция — только локальный сервер Ollama (`http://127.0.0.1:11434`) через прокси на `127.0.0.1:8787`.
- **Формат обмена с AI.** Запрос: `{"prompt": "...", "language": "ru", "task": {...}}`. Ответ: `{"questions": [{"field": "...", "question": "..."}]}`.

## Формула рейтинга

| Критерий | Баллы | Условие |
|---|---:|---|
| Контекст и потребность | 20 | ≥20 символов в каждом поле |
| Данные и материалы | 20 | ≥15 символов |
| Ожидаемый результат | 15 | ≥15 символов |
| Критерии успеха | 15 | ≥15 символов и есть цифра |
| Ограничения | 10 | ≥10 символов |
| Пользователи | 10 | ≥10 символов |
| Связь с бизнесом | 10 | контакт (email, телефон или @ник) и формат взаимодействия ≥8 символов |

В каждом поле должно быть не меньше 4 разных букв или цифр.

Уровни: 0–39 — Черновик, 40–69 — Рабочая, 70–89 — Готовая, 90–100 — Приоритетная.

## Ограничения

- Нет сервера и регистрации. Данные хранятся в localStorage одного браузера и не синхронизируются между устройствами. Роли переключаются действиями в интерфейсе.
- Рейтинг — эвристика полноты, а не проверка истинности фактов.
- Локальная заглушка AI задаёт шаблонные вопросы по пустым полям.
- Модель `qwen2.5:3b` используется только для русского и английского: вопросы появляются примерно за 3–9 секунд на тестовом ноутбуке. По-казахски модель пишет с ошибками, поэтому в казахском интерфейсе всегда работает локальная заглушка.
- Прогресс учитывается одним этапом на отклик, полного трекера проекта нет.
- Мобильная адаптация базовая.
