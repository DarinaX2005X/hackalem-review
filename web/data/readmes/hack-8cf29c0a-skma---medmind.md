# ЭКТ Автозаказ

## Что это за проект и какие задачи он решает

**ЭКТ Автозаказ** — помощник для менеджеров по закупкам ТОО «Электрокомплект». Он подсказывает, какие товары пора заказать у поставщиков и в каком количестве, чтобы снижать риск нехватки товара и не накапливать лишние запасы на складе.

При работе с большими таблицами сложно сопоставить продажи, остатки и ожидаемые поставки. Проект помогает:

- **Сократить ручные расчёты:** собирает данные из отчётов поставщиков IEK и Systeme Electric и готовит рекомендации по закупке.
- **Вовремя пополнить склад:** учитывает продажи, сезонность, остатки, резервы, товары в пути и сроки поставки.
- **Избежать лишних закупок:** учитывает уже доступный и заказанный товар, минимальную партию и кратность заказа.
- **Понять рекомендацию:** показывает причины расчёта и срочность закупки, позволяет проверить и изменить количество.
- **Подготовить заказ:** менеджер проверяет позиции, утверждает их и выгружает результат в файл.

Окончательное решение остаётся за менеджером: утверждение в системе не отправляет заказ поставщику автоматически.

## Запуск через Docker

### Подготовка

Понадобится установленный и запущенный Docker Desktop в режиме Linux containers или Docker Engine с Compose v2. Отдельно устанавливать Python, Node.js и базу данных не нужно.

Скачайте проект и откройте терминал в его корневой папке — там, где находится файл `compose.yaml`. Все команды ниже выполняются из этой папки и подходят для PowerShell, Bash и терминала macOS.

Проверьте, что Docker доступен:

```bash
docker --version
docker compose version
```

Если команда `docker` не найдена, убедитесь, что Docker установлен, и заново откройте терминал после установки.

### Первый запуск

Запустите приложение одной командой:

```bash
docker compose up --build -d
```

При первом запуске нужен интернет: Docker скачает зависимости и соберёт приложение. Дождитесь завершения команды — первая подготовка может занять несколько минут.

Откройте приложение в браузере: **[http://localhost:8080](http://localhost:8080)**.

В пустую базу автоматически загрузятся тестовые данные, поэтому для знакомства с проектом свои Excel-файлы не нужны. При повторном запуске существующие данные сохраняются.

### Расчёт рекомендаций

Тестовые данные содержат готовые заказы, но не прогнозы. Чтобы получить новый расчёт и подробные обоснования, выполните:

```bash
docker compose exec backend hackalem calc
```

После завершения обновите страницу и выберите новый расчёт в шапке приложения.

### Остановка и повторный запуск

Остановить приложение:

```bash
docker compose down
```

Данные сохранятся в Docker-томе. Для повторного запуска:

```bash
docker compose up -d
```

После обновления кода пересоберите приложение:

```bash
docker compose up --build -d
```

### Если приложение не открывается

Убедитесь, что Docker запущен, затем проверьте состояние контейнеров и сообщения об ошибках:

```bash
docker compose ps
docker compose logs -f
```

Выйти из просмотра сообщений можно сочетанием `Ctrl+C` — приложение продолжит работать.

### Дополнительные настройки

Для обычного запуска файл `.env` не нужен. Чтобы изменить порт или включить ИИ-ассистента, скопируйте `.env.example` в `.env` в корне проекта, рядом с `compose.yaml`. Если `.env` уже есть, отредактируйте его:

- `APP_PORT=8081` — открыть приложение по адресу [http://localhost:8081](http://localhost:8081), если порт 8080 занят.
- `OPENAI_API_KEY=ваш_ключ` — включить ИИ-ассистента. Без ключа остальные функции доступны.

После изменения настроек выполните `docker compose up -d`.
